# Style from studied patterns, not copied code

The Kosmos UI style (layered shadows instead of borders, power easings, fast transitions, dense typography) comes from patterns studied in existing products. We take only the ideas, write every component from scratch on Base UI, and record the resulting values and rules in the `kosmos-style` skill. Much of the studied code carries no license, so copying it would not be legal to publish; and code written for other primitives would not fit Base UI anyway.

## Consequences

- Tracked files name no product or company as a style source; the `kosmos-style` skill is the only reference.
- If code from an MIT-licensed project is ever copied verbatim, its copyright line must travel with it, as MIT requires.
