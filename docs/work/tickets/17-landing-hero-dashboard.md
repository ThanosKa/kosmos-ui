# 17: Landing με hero και ζωντανό dashboard

**What to build:** Η landing ξεκινά από την αρχή. Πρώτα ένα hero με τίτλο, μία γραμμή κειμένου, δύο CTAs (Browse components, GitHub) και την εντολή install. Από κάτω ένα αληθινό dashboard φτιαγμένο από τα 8 blocks στον νέο demo κόσμο, σε καμβά με tabs για ολόκληρες οθόνες (π.χ. Overview, Customers, Settings). Εκεί ο επισκέπτης αλλάζει live το accent, το radius και light ή dark. Το hero γίνεται η δωρεάν εκδοχή της Marketing κατηγορίας Hero, με δική του σελίδα στα docs. Κάθε ενότητα της landing έχει ετικέτα με το block από το οποίο είναι φτιαγμένη, με link στη σελίδα του.

**Blocked by:** 13, 16

**Status:** ready-for-agent

- [ ] Το Hero block υπάρχει στο registry ως Marketing, Free, με docs και κύκλο `build-component`
- [ ] Οι αλλαγές accent, radius και theme επηρεάζουν μόνο το dashboard και επιστρέφουν με reset
- [ ] Το dashboard δουλεύει σε 375px χωρίς οριζόντιο scroll της σελίδας
- [ ] Δεν υπάρχουν testimonials, εκπτώσεις, rotating headlines ή pop-ups
- [ ] Screenshots της landing σε light και dark, 375 και 1280, με agent visual review
