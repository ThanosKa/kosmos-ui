# 17: Sidebar submenus, workspace switcher, user menu

**What to build:** Ο χρήστης ενός dashboard ανοίγει submenus ενός επιπέδου στο Sidebar, αλλάζει workspace από έναν switcher στο πάνω μέρος και βρίσκει λογαριασμό και αποσύνδεση σε ένα user menu στο κάτω. Στο icon mode το submenu ανοίγει ως popover και ο switcher συμπτύσσεται στο εικονίδιό του. Το app-sidebar block τα χρησιμοποιεί.
