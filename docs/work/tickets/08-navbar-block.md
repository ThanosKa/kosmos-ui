# 08: Navbar block

**What to build:** Ο developer εγκαθιστά ένα marketing navbar: μένει στο πάνω μέρος, θολώνει στο scroll, έχει links με dropdown και κουμπιά δεξιά, και ανοίγει σε sheet στο κινητό. Το header του site γίνεται αυτό το block.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Το header του site είναι το block
- [ ] Το mobile sheet ανοίγει, κλείνει με Esc και κρατά το focus μέσα του
- [ ] Περνά τον κύκλο `build-component`, με τα screenshots του review στο black and white palette (μετά το 02)
- [ ] `pnpm types:check`, `pnpm lint`, `pnpm build` περνούν
