# 19: Pagination

**What to build:** Ο χρήστης περνά από σελίδα σε σελίδα σε μια μεγάλη λίστα, βλέπει «σελίδα X από Y», αλλάζει γραμμές ανά σελίδα, ή φορτώνει περισσότερα με ένα «Load more» που λέει πόσα μένουν.

**Blocked by:** None (can start immediately)
