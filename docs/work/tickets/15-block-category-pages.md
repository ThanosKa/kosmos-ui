# 15: Σελίδες block category και sidebar των Blocks

**What to build:** Τα blocks οργανώνονται σε block categories. Το sidebar του tab Blocks έχει τρεις ενότητες, Application, Marketing και AI, και δίπλα σε κάθε κατηγορία τον αριθμό των εκδοχών της. Μια ενότητα χωρίς κατηγορίες δεν φαίνεται. Κάθε σελίδα κατηγορίας έχει τίτλο, περιγραφή και τις εκδοχές μία κάτω από την άλλη, χωρίς στήλη «On this page». Οι σημερινές 8 σελίδες blocks γίνονται σελίδες κατηγοριών με μία εκδοχή, τη δωρεάν, η καθεμία. Η κατηγορία και το αν μια εκδοχή είναι Free ή Pro δηλώνονται στα δεδομένα του registry, ώστε το sidebar, οι αριθμοί και η landing να διαβάζουν το ίδιο σημείο.

**Blocked by:** 14

**Status:** ready-for-agent

- [ ] Κάθε registry block δηλώνει την κατηγορία του και ότι είναι Free
- [ ] Οι αριθμοί στο sidebar βγαίνουν από το registry και όχι γραμμένοι με το χέρι
- [ ] Τα παλιά URLs των 8 blocks οδηγούν στη σελίδα της κατηγορίας τους
- [ ] Ο όρος block category χρησιμοποιείται όπως στο `GLOSSARY.md`
- [ ] Playwright: το sidebar των Blocks δείχνει μόνο τις ενότητες που έχουν κατηγορίες
