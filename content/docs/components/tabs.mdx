## Usage

```tsx
import { Tabs, TabsContent, TabsList, TabsTrigger } from '@/components/ui/tabs';
```

```tsx
<Tabs defaultValue="overview">
  <TabsList>
    <TabsTrigger value="overview">Overview</TabsTrigger>
    <TabsTrigger value="activity">Activity</TabsTrigger>
  </TabsList>
  <TabsContent value="overview">…</TabsContent>
  <TabsContent value="activity">…</TabsContent>
</Tabs>
```

Use tabs for views of the same thing, like the overview and the activity of one project. To pick a value, like a time range for a chart, use a [Segmented control](/docs/components/segmented-control).

## Motion

The underline slides to the active tab over 300ms with `smooth-in-out`. Under reduced motion it fades out under the old tab and in under the new one instead of sliding. When horizontal tabs don't fit, the list scrolls sideways in a [Scroll area](/docs/components/scroll-area). The edge with tabs out of view past it fades out and a scrollbar shows.

## API

Tabs wraps the [Base UI Tabs](https://base-ui.com/react/components/tabs). Each part takes every prop of the Base UI part it renders.

### Tabs

Takes every Base UI `Tabs.Root` prop, such as:

  type={{

      default: '0',
    },
    value: {
      description: 'The active tab. Use with `onValueChange`.',
      type: 'any',
    },

      default: "'horizontal'",
    },
  }}
/>

### TabsList

Takes every Base UI `Tabs.List` prop, such as:

### Parts

| Part | What it is |
| --- | --- |
| `TabsList` | The row of tabs on a 1px divider, with the sliding underline. Base UI `Tabs.List` and `Tabs.Indicator`. |
| `TabsTrigger` | One tab. Takes `value` and `disabled`. Base UI `Tabs.Tab`. |
| `TabsContent` | The panel for the tab with the same `value`. `keepMounted` keeps hidden panels in the page. Base UI `Tabs.Panel`. |

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Moves focus to the active tab, then into the panel. |
| `ArrowRight` or `ArrowLeft` | Moves to the next or previous tab and shows its panel. At either end, it wraps around. In a right-to-left layout, the keys swap. |
| `ArrowDown` or `ArrowUp` | Does the same in a vertical list. |
| `Home` or `End` | Moves to the first or last tab. |
| `Enter` or `Space` | With `activateOnFocus={false}` on `TabsList`: shows the focused tab's panel. |

Tabs show their panel as focus reaches them. Pass `activateOnFocus={false}` to `TabsList` when a panel is slow to render.
