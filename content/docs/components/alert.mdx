## Usage

```tsx
import { Alert, AlertAction, AlertDescription, AlertTitle } from '@/components/ui/alert';
```

```tsx
<Alert variant="warning">
  <AlertTitle>Cirrus Weather is at 80% of its quota</AlertTitle>
  <AlertDescription>It will reach 3,000,000 events around October 18.</AlertDescription>
</Alert>
```

An alert is compact. Text with no title or no description is one 36px row. A title with a description stacks, the description in 13px muted text. An alert stays where it is until the page changes. For a short message that closes on its own, use a [Toast](/docs/components/toast). For a state of the whole page or project, use a [Banner](/docs/components/banner).

## Examples

### Variants

`neutral` is a card, for a note that needs no color. The other four take the status tint of their hue: `info` blue, `success` green, `warning` amber and `destructive` red. The fill, the text and the icon come from the tint. Links take the foreground color. Every tint text reads at 4.5:1 or more on its fill, in both themes. Each variant has its own icon, and the title says what happened, so the color is never the only signal.

### Appearance

`filled`, the default, draws a deep tint fill with text and icon in the hue and no edge. `subtle` is the outline: no fill, a 1px edge in the hue, and the same text and icon. It reads on the page and on a card. The neutral variant is always a card.

<ComponentPreview name="alert-appearance" />

### Links

A link inside an alert takes the foreground color, medium weight and a soft underline that turns solid on hover. The underline keeps the link from relying on color alone. Write the link as the next step, such as "Raise the allowance", not as a bare "here".

### Actions

Put buttons in `AlertAction`. In an alert narrower than 448px they sit under the text. From 448px they sit at the end of the row, centered on the text. Use `secondary` or `ghost` buttons, so the page keeps its one primary action.

<ComponentPreview name="alert-action" />

### Icon

Pass `icon` to replace the icon of the variant, or `icon={null}` for an alert without one.

### Screen readers

Alert renders a plain `<div>`, which screen readers read in the page order like any other text. When an alert appears because something went wrong, such as a failed save, give it `role="alert"` so screen readers say it at once. Leave the role off for an alert that is there when the page loads.

## API

### Alert

Renders a `<div>` and accepts all its props.

### AlertTitle

Renders a `<div>` through Base UI's [`useRender`](https://base-ui.com/react/utils/use-render). Pass `render={<h2 />}`, at the level that fits the page, when the alert heads a section.

### AlertDescription

Renders a `<div>` for the text under the title. Links inside it take the alert's link color.

### AlertAction

Renders a `<div>` for one or two buttons.
