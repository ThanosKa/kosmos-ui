## Usage

```tsx
import { ToolApproval } from '@/components/ui/tool-approval';
```

```tsx
<ToolApproval
  tool="projects.update_plan"
  title="Raise Cirrus Weather to the Scale plan?"
  description="Scale includes 8,000,000 events a month."
  details={[{ label: 'New plan', value: 'Scale' }]}
  status={status}
  decision={decision}
  decidedBy="Lena Park"
  decidedAt="14:02"
  onDecide={decide}
/>
```

The title asks the question in plain words, and the tool id below it shows exactly what will run. Details stay folded under **Show details** until someone needs them.

Tool approval holds no state of its own: you pass `status` and `decision`, and `onDecide` tells you which button the user pressed. While your request runs, set `status="submitting"` with the `decision` you are sending. The pressed button shows a spinner and all three stay disabled but focusable, so focus never jumps. Once it lands, set `status="decided"`.

A decided approval folds the details and the buttons away in 300ms and leaves a record line, such as "Allowed once by you · 14:02". When the reduced motion setting is on, they fade instead. If focus was on a button, it moves to the record line, and screen readers announce the record.

## Examples

### Irreversible action

Set `danger` for an action that can't be undone. Allow once turns red, Deny gets the raised secondary look, Always allow hides, and the `consequence` line shows above the buttons.

<ComponentPreview name="tool-approval-danger" />

### Decided

The badge turns to Allowed or Denied, and the record says what the user decided, by whom and when. Pass `decidedBy` as a role or a name from your own data.

<ComponentPreview name="tool-approval-decided" />

### Inside a host

Set `surface="none"` to drop the card and sit flat inside a card, a chat message or a timeline that already draws one. Set `allowAlways={false}` when the user must approve a tool every time.

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Moves to Show details, then Allow once, Always allow and Deny. |
| `Enter` or `Space` | Opens or closes the details, or presses the focused button. |
