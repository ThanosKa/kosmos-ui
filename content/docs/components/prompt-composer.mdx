## Usage

```tsx
import { PromptComposer } from '@/components/ui/prompt-composer';
```

```tsx
<PromptComposer
  models={[
    { id: 'claude-opus-5-5', name: 'Claude Opus 5.5', hint: 'Most capable' },
    { id: 'claude-sonnet-5-5', name: 'Claude Sonnet 5.5', hint: 'Balanced' },
  ]}
  efforts={['low', 'medium', 'high']}
  context={{ limit: 200_000, breakdown: [{ label: 'Conversation', value: 24_260 }] }}
  status={status}
  onSubmit={({ text, attachments, model, effort }) => send({ text, attachments, model, effort })}
  onStop={stop}
/>
```

Enter sends the message and Shift+Enter starts a new line. Enter never sends while an input method is still composing a word. After a send, the composer clears its text and attachments. The text box grows with the text up to 240px, then scrolls.

Each toolbar part appears only when you give it what it needs: `onAttach` adds the Attach button, `models` adds the [Model select](/docs/components/model-select) and `context` adds the [Usage meter](/docs/components/usage-meter). Without them, the composer is a text box and Send.

`status` follows the request. Set it to `submitting` while the message is on its way, and Send spins. Set it to `streaming` while the agent answers, and Send turns into Stop. Stop and Escape call `onStop`. People can type their next message while the agent answers, but it waits until `status` is back to `idle`. Send keeps focus as it changes, so a keyboard user can stop the answer from where they sent it.

## Examples

### Attachments

The composer shows attachments as chips and does not pick files itself. Call your own file picker or upload from `onAttach`, then pass the files in `attachments`. Each chip has a Remove button, and `onAttachmentsChange` gets the list without the removed file. A long file name truncates in its chip and shows in full in the tooltip of its Remove button.

<ComponentPreview name="prompt-composer-attachments" />

### Text only

Leave out `onAttach`, `models` and `context` for a plain message box, such as a note to a team or a reply in a thread. `onSubmit` gets the trimmed text.

<ComponentPreview name="prompt-composer-minimal" />

### Error and disabled

Pass `error` when a message fails to send. The composer takes a red ring and shows the text under it. Say what failed and how to fix it. Pass `disabled` with a `disabledReason` when people cannot write at all, and say what would let them write again.

## Motion

Send, its spinner and Stop cross-fade into each other in 150ms with `power3-out`, the incoming icon growing from `scale-80`. The spinner turns while `status` is `submitting`. A new attachment chip fades in. Under reduced motion the icons only cross-fade and the spinner pulses instead of turning. The text box grows without animation.

## Keyboard

| Key | Action |
| --- | --- |
| `Enter` | In the text box: sends the message. |
| `Shift` + `Enter` | In the text box: starts a new line. |
| `Escape` | While the agent answers: stops it. Inside the model menu or the usage panel, closes that instead. |
| `Tab` | Moves through the Remove buttons, the text box, Attach, the model select, the usage meter and Send. |
