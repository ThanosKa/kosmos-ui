## Installation

<ComponentInstall name="date-picker" />

This also brings [Calendar](/docs/components/calendar), [Popover](/docs/components/popover) and [Button](/docs/components/button).

## Usage

```tsx
import { DatePicker, DateRangePicker } from '@/components/ui/date-picker';
```

```tsx
<DatePicker aria-label="Due date" value={date} onValueChange={setDate} />
```

The field opens a [Calendar](/docs/components/calendar) in a popover, with the focus on the picked day, or today. Picking a day closes it and gives the focus back to the field, and so does Escape. The field has the look of a [Select](/docs/components/select) trigger and hugs its value; give it a width with `className`.

Name the field with `aria-label`, or with a label that points to its `id`, as in the example above. Pass `name` and the day goes with the form as `2026-10-25`.

## Examples

### Range

`DateRangePicker` picks a first and a last day over two months, one on a phone. Beside them sit quick ranges: today, yesterday, the last 7, 30 and 90 days, this month and last month. A quick range picks at once; otherwise the range is set when its second day is picked. The field names the quick range a value matches, such as "Last 30 days", and writes the dates for any other.

<ComponentPreview name="date-picker-range" />

Pass your own quick ranges with `ranges`, or `[]` for none. `lib/dates.ts` has the helpers to make them:

```tsx
import { lastDays, thisMonth } from '@/lib/dates';

const ranges = [
  { label: 'Last 14 days', ...lastDays(14) },
  { label: 'Month to date', ...thisMonth() },
];
```

### In a chart card

Put a `DateRangePicker` in the action slot of a [Chart card](/docs/components/chart-card), and pass `max` so no range reaches past today. Beside a Button, give the field the Button's height with `className="h-7.5"`.

<ComponentPreview name="date-picker-chart-card" />

### Another language

Pass `locale`, then `placeholder`, and on `DateRangePicker` the quick ranges, `rangesLabel`, `startHint` and `endHint`. `formatValue` writes the value on the field your own way.
