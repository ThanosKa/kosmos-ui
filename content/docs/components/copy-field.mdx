## Usage

```tsx
import { CopyField } from '@/components/ui/copy-field';
```

```tsx
<CopyField label="webhook URL" aria-label="Webhook URL" value="https://hooks.acme.example/v1/fernhill/events" />
```

```tsx
<CopyField secret label="secret key" aria-label="Secret key" value={secretKey} />
```

The button at the end copies `value`. Once the value is on the clipboard, the icon turns into a check mark for two seconds and screen readers hear "Webhook URL copied". When the browser refuses, as it does on a page served over plain http, the field shows and selects the value instead. You can then copy it with the keyboard, and screen readers hear that. A revealed secret stays visible until the eye button hides it again.

`label` says what the value is. It names the buttons ("Copy webhook URL", "Show secret key") and the message screen readers hear. The field itself takes its name from a [Field](/docs/components/field) label, or from `aria-label` on its own.

With `secret`, the field shows 12 dots and the last four characters, so people can tell two keys apart without seeing them. Every secret takes the same 12 dots, so the field gives away nothing of its length. A secret shorter than 16 characters shows only the dots. The eye button shows the value and hides it again. The copy button copies the value even with the dots showing. With the dots showing, the page holds only the dots.

Keys and URLs read left to right on a right-to-left page too. A value too long for the field ends in an ellipsis. The full value is what the button copies.

The hiding and the copying come from `@kosmos/secret` and `@kosmos/use-copy`, which install with it as `lib/secret.ts` and `hooks/use-copy.ts`. You can use them in your own code too. `maskSecret(secret)` returns the dots and the last four characters. `useCopy(text, { onFailure })` returns the result (`'idle' | 'copied' | 'failed'`) and a function that copies.

## API

CopyField renders an [Input Group](/docs/components/input-group) and passes its other props to the read-only input, such as `aria-label`, `id` and `name`. `className` goes to the field.
