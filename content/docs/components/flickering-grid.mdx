## Usage

```tsx
import { FlickeringGrid } from '@/components/ui/flickering-grid';
```

```tsx
<section className="relative isolate overflow-hidden">
  <FlickeringGrid />
  {/* the content */}
</section>
```

The grid fills the nearest positioned parent and sits behind its content, so give the parent `relative isolate`. It takes no room and cannot shift the layout. To fade it out toward the edges, pass a mask in `className`, as in `mask-[radial-gradient(ellipse_60%_70%_at_50%_45%,black,transparent)]`.

The squares take the preset's accent. A preset with no accent gives ink. The colour follows the light and dark theme without a reload. It never takes the brand colour.

## Accessibility

The grid is decorative, so it is `aria-hidden` and screen readers skip it. When the visitor asks for reduced motion, it draws one still grid and never animates. Otherwise it stops drawing while it is off screen and while the tab is hidden, so it costs nothing it cannot be seen. It draws on a canvas that is as large as its parent, so nothing shifts while it loads.
