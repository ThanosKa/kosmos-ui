## Usage

```tsx
import { Textarea } from '@/components/ui/textarea';
```

```tsx
<Textarea name="note" aria-label="Note" placeholder="Add a note for the team" />
```

Textarea starts 64px tall and grows with its content (`field-sizing: content`). Set a taller start with a `min-h-*` class, or cap the growth with `max-h-*`, after which it scrolls.

## API

Textarea is a Base UI [`Field.Control`](https://base-ui.com/react/components/field) rendered as a `<textarea>`, so it takes its label, description and error from a Field. It accepts all `<textarea>` props.
