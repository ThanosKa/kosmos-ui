## Usage

```tsx
import { StatCard, StatCardDelta, StatCardLabel, StatCardSparkline, StatCardValue } from '@/components/ui/stat-card';
```

```tsx
<StatCard>
  <StatCardLabel>Active users</StatCardLabel>
  <StatCardValue>144,600</StatCardValue>
  <StatCardDelta value={9.6}>vs September</StatCardDelta>
  <StatCardSparkline data={trend} aria-label="Active users, last 30 days, up 9.6%" />
</StatCard>
```

Pass the value already formatted, in the user's locale and currency. Write a million and up compact (28.5M), so the number fits a narrow card. A value too wide for its card truncates. Lay several cards out in a grid with `gap-4`: each one is its own card.

## Examples

### When falling is good

`StatCardDelta` takes the change as a number, 9.6 for a 9.6% rise, and writes it with an arrow and a sign: ↗ +9.6%, ↘ −11.1%, → 0%. A rise is green and a fall red. For a metric such as errors or latency, set `goodWhen="down"` so a fall is green. For one that is neither good nor bad, `goodWhen="neither"` keeps it grey. A change in a rate reads in percentage points with `unit="points"`.

<ComponentPreview name="stat-card-good-when" />

The arrow and the sign carry the direction, so the change reads the same in grayscale and for color-blind readers. The green and red only say whether it is good news. A change that rounds to 0.0 is flat. For a metric with no earlier period, leave the delta out and say so with `StatCardDescription`.

### Loading

`loading` swaps the value, the change and the sparkline for skeletons of the same size, so the card keeps its height when the data arrives. The label stays.

## Accessibility

- The change is text: screen readers say "+9.6%" and the words beside it. Put the comparison in `children` ("vs September"), or in a `sr-only` span when the page says it once for every card.
- The sparkline is one image. Say what it shows, change included, in its `aria-label`.
- `loading` sets `aria-busy` on the card.

## API

### StatCard

Renders a `<div>` through Base UI's [`useRender`](https://base-ui.com/react/utils/use-render) and accepts all of its props.

<TypeTable
  type={{
    loading: {
      description: 'Swaps the value, the change and the sparkline for skeletons. The label stays.',
      type: 'boolean',
      default: 'false',
    },
  }}
/>

### StatCardLabel

Renders a `<span>` for what the number counts. A long label wraps.

### StatCardValue

Renders a `<span>` for the formatted number, in the stat role with tabular figures.

### StatCardDelta

Renders a `<span>` with the change in a tag, then its `children` in muted text. Renders nothing when `value` is not a finite number (a change against an earlier zero) and there are no `children`.

<TypeTable

/>

### StatCardDescription

Renders a `<p>` in muted text, for a stat with no change to show ("No earlier period").

### StatCardSparkline

The [Sparkline](/docs/components/chart#sparkline) across the card under the number, 40px high, in `--chart-1`. Takes its props, and `aria-label` is required.
