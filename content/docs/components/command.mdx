Command installs [Dialog](/docs/components/dialog) and [Kbd](/docs/components/kbd) with it.

## Usage

```tsx
import {
  Command,
  CommandDialog,
  CommandEmpty,
  CommandInput,
  CommandItem,
  CommandList,
} from '@/components/ui/command';
```

```tsx
const commands = [
  { value: 'new-task', label: 'Create task' },
  { value: 'settings', label: 'Open settings' },
];

<CommandDialog open={open} onOpenChange={setOpen}>
  <Command items={commands}>
    <CommandInput placeholder="Search for a command…" />
    <CommandEmpty>No results found.</CommandEmpty>
    <CommandList>
      {(item) => (
        <CommandItem key={item.value} value={item} onClick={() => run(item)}>
          {item.label}
        </CommandItem>
      )}
    </CommandList>
  </Command>
</CommandDialog>
```

`Command` takes the whole list as `items` and filters it by each item's `label` as you type. The first match stays highlighted, so typing and pressing Enter runs it. The up and down arrows move the highlight; Escape or a click outside closes the palette and puts focus back where it was.

The palette has no shortcut of its own. Listen for ⌘K (Ctrl+K on Windows and Linux) on `document` and toggle `open`, as the demo above does.

### Groups

Pass groups as `{ value, items }`. Render each with a `CommandGroup` that gets the group's `items`, a `CommandGroupLabel` and a `CommandCollection` for its items:

```tsx
<CommandList>
  {(group) => (
    <CommandGroup key={group.value} items={group.items}>
      <CommandGroupLabel>{group.value}</CommandGroupLabel>
      <CommandCollection>
        {(item) => (
          <CommandItem key={item.value} value={item}>
            {item.label}
          </CommandItem>
        )}
      </CommandCollection>
    </CommandGroup>
  )}
</CommandList>
```

## Examples

### Inline

Without `CommandDialog`, `Command` renders as a panel on the page, for a searchable list inside a popover or a side panel. Give its input an `aria-label` that says what it searches.

## Motion

The palette appears and closes without animation, because it opens from a keyboard shortcut and should be ready the moment you type. The highlight changes color in 100ms.

## API

### Parts

| Part | What it is |
| --- | --- |
| `CommandInput` | The search field, with a search icon. Base UI `Autocomplete.Input`. Its accessible name defaults to "Search commands". |
| `CommandList` | The scrolling list of matches, up to 20rem tall. Base UI `Autocomplete.List` in a Scroll Area. |
| `CommandEmpty` | Text shown while nothing matches, announced to screen readers. Base UI `Autocomplete.Empty`. |
| `CommandGroup` | One group of matches. Base UI `Autocomplete.Group`. |
| `CommandGroupLabel` | Names a group. Base UI `Autocomplete.GroupLabel`. |
| `CommandCollection` | Renders the items of its group. Base UI `Autocomplete.Collection`. |
| `CommandItem` | One command. Base UI `Autocomplete.Item`. |
| `CommandSeparator` | A 1px line between items. Base UI `Autocomplete.Separator`. |
| `CommandShortcut` | A `KbdGroup` at the end of an item, for the command's own shortcut. |
| `CommandFooter` | A bar under the list. Without children it shows the keys that move, run and close. |

## Keyboard

Focus stays in the search field: typing filters the list, and the keys below move the highlight through the matches.

| Key | Action |
| --- | --- |
| `ArrowDown` | Highlights the next command. From the last, it goes back to the first. |
| `ArrowUp` | Highlights the previous command. From the first, it goes to the last. |
| `Home` or `End` | Highlights the first or last command. |
| `Enter` | Runs the highlighted command. |
| `Escape` | In a `CommandDialog`, closes the palette and puts focus back where it was. |
