## Usage

```tsx
import Image from 'next/image';
import { BrowserFrame } from '@/components/ui/browser-frame';
```

```tsx
<BrowserFrame url="acme.example/overview">
  <Image src="/overview.png" alt="The overview page of Acme" width={1600} height={1000} className="block w-full" />
</BrowserFrame>
```

The frame draws the window and nothing else: the bar, the card surface, its shadow and its 16px radius. The content is yours, a screenshot or a live component. Give a screenshot the content outline from the style, and an `alt` that says what it shows.

## Examples

### Tilt

`tilt` leans the window back in perspective and stands it straight when the pointer is over it. Under reduced motion it stands straight from the start. Leave a little room above it, since the top edge swings outward as it leans.

<ComponentPreview name="browser-frame-tilt" />

## Accessibility

The bar, with its dots and address, is decorative and `aria-hidden`. The content keeps its own semantics.

## API

BrowserFrame is a `<div>` and accepts all of its props. It wraps no Base UI part.
