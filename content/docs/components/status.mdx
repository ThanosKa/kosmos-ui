## Usage

```tsx
import { StatusBadge, StatusDot, StatusIcon, type Status } from '@/components/ui/status';
```

```tsx
<StatusIcon status="done" label="Done" />
<StatusDot status="error">Failed</StatusDot>
<StatusBadge status="running">Running</StatusBadge>
```

There are six states: `pending`, `running`, `waiting`, `done`, `error` and `skipped`. Map your own words onto them, such as queued to `pending`, needs approval to `waiting` and failed to `error`, and write those words as the label.

The color sits on the icon or the dot, never on the text. Each state has its own icon shape and its own word. The label and the shape carry the meaning without the color.

The running icon spins. When the reduced motion setting is on, it pulses instead. A new icon fades in as a status changes, with a small scale that the reduced motion setting turns off.

## Examples

### Icons

`StatusIcon` is 16px, to lead a row. Pass `className="size-3.5"` for a 14px icon beside 13px text.

<ComponentPreview name="status-icons" />

### Dots

`StatusDot` is a state in a table cell, a list or a detail page. It is a 6px dot beside the word, in the text color around it, with no pill. The dot takes the status tint of its state: gray for `pending` and `skipped`, blue for `running` (it pulses), amber for `waiting`, green for `done` and red for `error`. A label too long for its slot truncates.

<ComponentPreview name="status-dots" />

For a code, such as an HTTP status or a method, use a [Badge](/docs/components/badge#codes) hue instead.

### Badges

`StatusBadge` is the neutral Badge with a colored dot for `waiting`, `done` and `error`, and with the row icon for `pending`, `running` and `skipped`. A label too long for its slot truncates, so keep it to a word or two, or pass `title` with the full text.

<ComponentPreview name="status-badges" />

### Steps

A list of steps, each led by its icon. When no text beside the icon names the status, pass `label`, so screen readers read it.

## API

### StatusIcon

<TypeTable
  type={{
    status: {
      description: 'The state to show.',
      type: "'pending' | 'running' | 'waiting' | 'done' | 'error' | 'skipped'",
      required: true,
    },
    label: {
      description: 'Names the status for screen readers. Leave it out when text beside the icon already says it, and the icon stays hidden from them.',
      type: 'string',
    },
    className: {
      description: 'Classes for the icon, such as `size-3.5`.',
      type: 'string',
    },
  }}
/>

### StatusDot

Renders a `<span>` and accepts all its props, and:

<TypeTable
  type={{

      required: true,
    },
    children: {
      description: 'The word, in your own words.',
      type: 'ReactNode',
    },
  }}
/>

### StatusBadge

Takes every [Badge](/docs/components/badge) prop except `variant`, and:

<TypeTable
  type={{

      required: true,

    children: {

### formatDuration

The AI components write durations with `formatDuration` from `@kosmos/format`, which installs with them: `1.4s` under 10 seconds, `30s` under a minute, then `2m 05s` and `1h 02m`.

```tsx
import { formatDuration } from '@/lib/format';

formatDuration(125_000); // "2m 05s"
```
