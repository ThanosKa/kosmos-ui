## Usage

```tsx
import { BlurFade } from '@/components/ui/blur-fade';
```

```tsx
<BlurFade>
  <section>{/* a section of the page */}</section>
</BlurFade>
```

The content is in the markup and visible without JavaScript. Once the page is live, content below the fold waits hidden and comes in the first time a part of it scrolls into view. Content already on screen stays as it is, so nothing flashes at load. Only opacity, blur and a few pixels of translation change, so the layout never shifts. It runs once per element.

## Accessibility

The content stays in the accessibility tree the whole time. Under reduced motion it only fades in, with no blur and no rise.

## API

BlurFade is a `<div>` and accepts all its props. It wraps no Base UI part.
