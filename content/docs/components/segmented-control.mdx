## Usage

```tsx
import { SegmentedControl, SegmentedControlItem } from '@/components/ui/segmented-control';
```

```tsx
<SegmentedControl aria-label="Time range" defaultValue="30d">
  <SegmentedControlItem value="7d">7 days</SegmentedControlItem>
  <SegmentedControlItem value="30d">30 days</SegmentedControlItem>
  <SegmentedControlItem value="90d">90 days</SegmentedControlItem>
</SegmentedControl>
```

Give the control an `aria-label`, or point `aria-labelledby` at a visible label. Keep it to two to five options with one or two words each; for more options, use a [Select](/docs/components/select). To switch between panels of content, use [Tabs](/docs/components/tabs).

Underneath it is a radio group, so exactly one item is always selected and `name` submits the value with a form.

## Motion

The raised surface fades onto the selected item over 150ms, so nothing slides and reduced motion needs no change. When the control is wider than its container, the labels wrap instead of overflowing.

## API

SegmentedControl wraps the [Base UI Radio Group](https://base-ui.com/react/components/radio), and each item a Base UI Radio.

### SegmentedControl

Takes every Base UI `RadioGroup` prop, such as `name` and `required`, plus `size`:

<TypeTable
  type={{

      description: 'The selected item. Use with `onValueChange`.',
      type: 'string',
    },
    onValueChange: {
      description: 'Called with the value of the newly selected item.',
      type: '(value: string, eventDetails) => void',
    },
    size: {
      description: '`md` matches a 30px Button, `sm` a 24px one.',
      type: "'sm' | 'md'",
      default: "'md'",
    },
    disabled: {
      description: 'Turns off every item.',
      type: 'boolean',
      default: 'false',
    },
  }}
/>

### SegmentedControlItem

Takes every Base UI `Radio.Root` prop, such as:

<TypeTable
  type={{

    disabled: {
      description: 'Turns off this item only.',
      type: 'boolean',
      default: 'false',
    },
  }}
/>

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Moves focus to the selected item, then on to the next control. |
| `ArrowRight` or `ArrowDown` | Selects the next item. From the last, it goes back to the first. |
| `ArrowLeft` or `ArrowUp` | Selects the previous item. From the first, it goes to the last. |
| `Space` | Selects the focused item. |

In a right-to-left layout, `ArrowLeft` and `ArrowRight` swap.
