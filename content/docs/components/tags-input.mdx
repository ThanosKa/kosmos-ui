## Usage

```tsx
import { isEmail } from '@/lib/tags';
import { TagsInput } from '@/components/ui/tags-input';
```

```tsx
<TagsInput aria-label="Invite by email" name="emails" delimiters={[',', ';', ' ']} validate={isEmail} placeholder="name@acme.example" />
```

Typing a delimiter or pressing Enter turns the text before it into a tag. So does leaving the field, so a form never drops the last one. A pasted list becomes one tag per line or delimiter. The field skips a tag already in the list, whatever its case. It announces each add to screen readers, with how many it skipped.

`validate` marks the tags it rejects in red with an alert icon, and keeps them, so people can see the typo and remove it. `isEmail`, installed with the component, checks for a name, one @ and a domain with a dot. Pair it with a FieldError that names the bad address.

`max` caps the list. Once it is full, the input takes no more text until someone removes a tag.

To choose only from a list, use the [Combobox](/docs/components/combobox) with `multiple`.

## API

TagsInput builds on the [Base UI Combobox](https://base-ui.com/react/components/combobox) with `multiple`, using the [Combobox](/docs/components/combobox) chips. Other props go to the text input, such as `placeholder`, `aria-label` and `aria-invalid`.

### Helpers

`lib/tags.ts` installs with the component, for code that handles tags outside the input, such as a server action that checks an invite list.

| Function | What it does |
| --- | --- |
| `isEmail(value)` | Whether the text reads as an email address. |
| `splitTags(text, delimiters)` | The tags in a text, split on each delimiter and line break, trimmed. |
| `addTags(tags, incoming, { max, allowDuplicates })` | The list after adding, with the tags it added and those it left out as duplicates or past the limit. |

## Keyboard

| Key | Action |
| --- | --- |
| `Enter` or a delimiter | Adds the typed text as a tag. With a suggestion highlighted, Enter adds the suggestion. |
| `ArrowLeft` | From the start of the input: moves onto the last tag, then along the tags. |
| `Backspace` | In an empty input: removes the last tag. On a tag: removes it. |
| `Escape` | Clears the text in the input, or closes the suggestions. The tags stay. |
| `ArrowDown` | With `suggestions`: highlights the next suggestion. |
