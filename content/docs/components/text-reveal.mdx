Ported from the text reveal of [Magic UI](https://github.com/magicuidesign/magicui) (MIT) and restyled to the Kosmos tokens. Its copyright line lands next to the component, in `LICENSE-MAGIC-UI`.

## Usage

```tsx
import { TextReveal } from '@/components/ui/text-reveal';
```

```tsx
<h1>
  <TextReveal>Dashboard UI with the details already done</TextReveal>
</h1>
```

The words are plain text in the markup, so search engines, screen readers and a browser without JavaScript get the whole title. The entrance is a CSS transition from the `starting` style, so it plays on the first paint, with no hydration wait. Pass a string: a title with markup inside cannot be split into words.

## Accessibility

Nothing is hidden from assistive technology and the text never changes. Under reduced motion the words are there at once, with no blur and no rise.

## API

TextReveal is a `<span>` and accepts all of its props. It wraps no Base UI part.
