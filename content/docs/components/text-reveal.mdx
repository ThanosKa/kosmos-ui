## Usage

```tsx
import { TextReveal } from '@/components/ui/text-reveal';
```

```tsx
<h1>
  <TextReveal>Dashboard UI with the details already done</TextReveal>
</h1>
```

The words are plain text in the markup, so search engines, screen readers and a browser without JavaScript get the whole title. By default the entrance is a CSS transition from the `starting` style, so it plays on the first paint, with no hydration wait. Pass a string: a title with markup inside cannot be split into words.

For a section further down the page, set `trigger="view"`: text below the fold waits hidden and plays once, the first time it scrolls into view; text already on screen stays put. The stagger shortens for a long text, so the last word lands within a second.

## Accessibility

Nothing is hidden from assistive technology and the text never changes. Under reduced motion the words fade in together, with no blur and no rise.

## API

TextReveal is a `<span>` and accepts all of its props. It wraps no Base UI part.
