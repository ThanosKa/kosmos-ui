## Usage

```tsx
import { ChecklistIllustration, LayerStackIllustration, SyncIllustration } from '@/components/ui/illustrations';
```

```tsx
<div className="overflow-hidden rounded-2xl bg-muted">
  <LayerStackIllustration />
</div>
```

Each illustration uses tokens and no image. It is a 4:3 stage that fills the width of its container and scales with it. Put it in a bento tile or a feature card and let the container set the size. It carries no text and assistive technology skips it, so the words around it say what it shows.

## Examples

### Layer stack

Four cards stacked like pages. They fan out once the stack scrolls into view. With `trigger="hover"` they fan out while the pointer is over the stack and close when it leaves.

## Accessibility

The illustrations are decoration and carry `aria-hidden`. The pulses and the ticking run only while the illustration is on screen. Under reduced motion nothing moves: the stack stands fanned out, the pulses rest mid-link and every row has its tick.
