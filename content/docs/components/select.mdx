## Usage

```tsx
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from '@/components/ui/select';
```

```tsx
const statuses = [
  { value: 'todo', label: 'To do' },
  { value: 'done', label: 'Done' },
];

<Select name="status" items={statuses} defaultValue="todo">
  <SelectTrigger aria-label="Status">
    <SelectValue placeholder="Pick a status" />
  </SelectTrigger>
  <SelectContent>
    {statuses.map((status) => (
      <SelectItem key={status.value} value={status.value}>
        {status.label}
      </SelectItem>
    ))}
  </SelectContent>
</Select>;
```

Pass `items` to Select so the trigger shows the item's label, "To do", instead of its value, `todo`, before the list has opened.

## API

Select wraps the [Base UI Select](https://base-ui.com/react/components/select). Each part takes the props of the Base UI part it renders.

### Parts

| Part | What it is |
| --- | --- |
| `SelectTrigger` | The button that opens the list, with a chevron. Base UI `Select.Trigger` and `Select.Icon`. |
| `SelectGroup` | Groups related items. Base UI `Select.Group`. |
| `SelectGroupLabel` | The heading of a group. Base UI `Select.GroupLabel`. |
| `SelectSeparator` | A line between groups. Base UI `Select.Separator`. |

## Keyboard

| Key | Action |
| --- | --- |
| `Enter`, `Space`, `ArrowDown` or `ArrowUp` | On the trigger: opens the list with the selected item highlighted. |
| `A`–`Z` | On the trigger: selects the next item that starts with the letters typed, without opening the list. In the list: highlights it. |
| `ArrowDown` or `ArrowUp` | Highlights the next or previous item. It stops at either end. |
| `Home` or `End` | Highlights the first or last item. |
| `Enter` or `Space` | Selects the highlighted item and closes the list. |
| `Escape` | Closes the list without changing the value, and puts focus back on the trigger. |
| `Tab` | Closes the list without changing the value, and moves to the next control. |
