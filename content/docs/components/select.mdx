## Usage

```tsx
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from '@/components/ui/select';
```

```tsx
const statuses = [
  { value: 'todo', label: 'To do' },
  { value: 'done', label: 'Done' },
];

<Select name="status" items={statuses} defaultValue="todo">
  <SelectTrigger aria-label="Status">
    <SelectValue placeholder="Pick a status" />
  </SelectTrigger>
  <SelectContent>
    {statuses.map((status) => (
      <SelectItem key={status.value} value={status.value}>
        {status.label}
      </SelectItem>
    ))}
  </SelectContent>
</Select>;
```

Pass `items` to Select so the trigger shows the item's label, "To do", instead of its value, `todo`, before the list has opened.

## Keyboard

| Key | When the list is closed | When the list is open |
| --- | --- | --- |
| Enter, Space, ↓, ↑ | Opens the list | Enter and Space choose the highlighted item |
| ↓, ↑, Home, End | | Move the highlight |
| A letter | | Jumps to the next item that starts with it |
| Escape | | Closes the list; focus goes back to the trigger |
| Tab | Moves to the next control | Closes the list and moves to the next control |

### Position

The list opens over the trigger with the chosen item on top of the value, as native menus do on macOS. Set `alignItemWithTrigger={false}` on SelectContent to open it below the trigger instead. On touch screens it always opens below.

<ComponentPreview name="select-position" />

### Disabled

Disable the whole Select with `disabled` on Select, or one option with `disabled` on its SelectItem.
