## Examples

### Status

`success`, `warning` and `destructive` keep the neutral surface and add a colored dot. The label carries the meaning, so write one that reads on its own, such as "Payment failed" instead of "Error". The demo above shows all five looks.

### Tags

For categories, such as a segment, a plan or a label, use a hue: `orange`, `blue`, `amber`, `magenta`, `green` or `red`. Each one tints the pill with its hue and draws its text in a darker or lighter step of the same hue, which passes 4.5:1 in both themes. Give each category one hue and keep it everywhere. Orange, blue, green and red are the same colors as the status tints of those hues. A status keeps the neutral pill with a dot.

<ComponentPreview name="badge-tags" />

### Codes

For a code, such as an HTTP status or a method, use a status tint: `tint-gray`, `tint-blue`, `tint-green`, `tint-teal`, `tint-orange` or `tint-red`. The pill takes the tint's fill and text, with no edge, so it reads as a value rather than a category. Map status codes by class: 2xx `tint-green`, 4xx `tint-orange`, 5xx `tint-red` and anything else `tint-gray`. Methods take GET `tint-green`, POST `tint-blue`, PATCH `tint-orange` and DELETE `tint-red`.

<ComponentPreview name="badge-codes" />

### Current item

Inside the current item of a nav, the element with `aria-current`, `tint-blue`, `tint-green`, `tint-orange` and `tint-red` fill with their solid step under white text, at 4.5:1 or more in both themes. An API reference uses it to mark the method of the page you are on.

<ComponentPreview name="badge-current" />

### With an icon

An icon inside a badge is sized to 12px. Put it before the label, or after it when it points somewhere, like an arrow on a link.

<ComponentPreview name="badge-icon" />

### Counts

Numbers in a badge use tabular figures, so a count that changes keeps its width. Use `primary` for a count that needs attention, such as unread items, and `secondary` for the rest.

<ComponentPreview name="badge-count" />

### Link

Pass an `<a>` through `render` to make the whole badge a link. It gets a hover background and the focus outline.

<ComponentPreview name="badge-link" />

### Long labels

A badge never wraps. When the label can be longer than its slot, wrap it in `<span className="min-w-0 truncate">` and show the full text somewhere the user can reach, such as the detail view.

## API

Badge renders a `<span>` through Base UI's [`useRender`](https://base-ui.com/react/utils/use-render) and accepts all of its props.

`badgeVariants({ variant })` returns the same classes, for elements that should look like a Badge without being one.
