## Usage

```tsx
import { Calendar } from '@/components/ui/calendar';
```

```tsx
<Calendar value={date} onValueChange={setDate} aria-label="Due date" />
```

Calendar picks whole days: it hands you a `Date` at midnight in the user's time zone. Every month takes six rows, so the calendar keeps its height from one month to the next, and screen readers hear the new month when it changes.

Tab lands on one day: the picked day, else today, else the first of the month. From there the arrow keys move a day or a week, Home and End go to the start and the end of the week, Page Up and Page Down move a month, and a year with Shift. Enter or Space picks the day. A day that can't be picked keeps its place in that path, so the arrows never jump over it.

Most of the time you want Calendar inside a [Date picker](/docs/components/date-picker), which opens it from a field.

## Examples

### Range

Pass `mode="range"`. The first pick starts the range and the second ends it, in either order. Until then the days up to the pointer show the range it would make. `months={2}` puts two months side by side, and they wrap one under the other when the room runs out.

<ComponentPreview name="calendar-range" />

`onValueChange` runs on each pick: with `{ from }` after the first, and with `{ from, to }` after the second.

### Days that can't be picked

`min` and `max` set the first and last day, and the month buttons stop there. The days past them fade. `isDateDisabled` turns off single days, such as weekends, which fade and are struck through.

<ComponentPreview name="calendar-limits" />

### Another language

Pass `locale` for the month and weekday names, the digits and the first day of the week, which follows the locale: Sunday in the United States, Monday in most of Europe, Saturday in Egypt. Set `weekStartsOn` to choose it yourself. Name the month buttons with `previousMonthLabel` and `nextMonthLabel`. Inside a right-to-left page, the grid and the arrow keys turn around with it.

<ComponentPreview name="calendar-locale" />

### Dates in your own code

`lib/dates.ts` holds the day counting Calendar does, for your own code too:

```tsx
import { addDays, formatRange, lastDays, rangeLength } from '@/lib/dates';

const range = lastDays(30); // the last 30 days, today included
formatRange(range, 'en-US'); // "Sep 26 – Oct 25, 2026"
rangeLength(range); // 30
```
