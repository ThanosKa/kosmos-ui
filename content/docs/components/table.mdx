## Usage

```tsx
import {
  Table,
  TableBody,
  TableCaption,
  TableCell,
  TableFooter,
  TableHead,
  TableHeader,
  TableRow,
} from '@/components/ui/table';
```

```tsx
<Table>
  <TableHeader>
    <TableRow>
      <TableHead>Invoice</TableHead>
      <TableHead className="text-end">Amount</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell>INV-1042</TableCell>
      <TableCell className="text-end">$2,400.00</TableCell>
    </TableRow>
  </TableBody>
</Table>
```

Headers are 38px tall and rows 42px. 1px borders separate the rows, and body rows highlight on hover. The whole table uses tabular numbers, so digits line up down a column. Align number columns to the end with `text-end`.

The parts and their names match shadcn's Table, so data table code written for it, such as TanStack Table examples, works unchanged. For sorting, filters, selection and pages on top of it, use [Data table](/docs/components/data-table).

## Examples

### Selected rows

Mark a selected row with `data-state="selected"`. With TanStack Table, pass `data-state={row.getIsSelected() ? 'selected' : undefined}`.

<ComponentPreview name="table-selection" />

### Wide tables on small screens

A table wider than its container scrolls sideways inside it, so the page never scrolls sideways. While columns run out of view, the clipped edge fades out and a scrollbar shows under the table. The scroll area can take keyboard focus, and the arrow keys scroll it. Narrow the preview to see it.

<ComponentPreview name="table-wide" />

### Long text

Cells don't wrap. For a column of long text, give the table `className="table-fixed"`, set column widths on the `TableHead`s and add `truncate` to the cells. Put the full value in a `title`, or in a detail view the row opens, so it is never lost.

## API

Each part renders the matching native element and accepts all its props. No part wraps a Base UI part.

### Table

Renders a `<table>` inside a [Scroll Area](/docs/components/scroll-area), so a wide table scrolls sideways instead of widening the page. Takes every `<table>` prop, plus:

<TypeTable
  type={{
    containerClassName: {
      description: 'Classes for the scroll area around the `<table>`.',
      type: 'string',
    },
  }}
/>

### TableRow

Renders a `<tr>` that highlights on hover. Takes every `<tr>` prop, plus:

<TypeTable
  type={{
    'data-state': {
      description: "Set to `'selected'` to highlight the row as selected.",
      type: "'selected'",
    },
  }}
/>

### Parts

| Part | What it is |
| --- | --- |
| `TableHeader` | The header rows. A `<thead>`. |
| `TableBody` | The body rows. A `<tbody>`. |
| `TableFooter` | The footer rows, such as totals, in medium weight below a 1px line. A `<tfoot>`. |
| `TableHead` | A header cell. A `<th>`. |
| `TableCell` | A body cell. A `<td>`. |
| `TableCaption` | Describes the table, under it, lined up with the first column, so it stays in view while a wide table scrolls. A `<caption>`. |

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Focuses the table while its columns overflow. Tab skips a table that fits. |
| `ArrowRight` or `ArrowLeft` | Scrolls sideways to the hidden columns. |
