## Usage

```tsx
import { Separator } from '@/components/ui/separator';
```

```tsx
<Separator />
<Separator orientation="vertical" />
```

Reach for space first: a larger gap often separates two groups well enough without a line. Use a Separator where the groups sit close together, such as the header and body of a card.

A vertical Separator stretches to the height of its flex row. Outside a flex row, give it a height with `className`.

The line is a real border, so it stays visible in forced-colors mode, where box shadows disappear.
