## Installation

<ComponentInstall name="chart" />

This installs [Recharts](https://recharts.github.io), the chart library shadcn's charts also use, and `react-is`, which Recharts needs. On React 18, pin `react-is` to version 18.

## Usage

```tsx
import { GrowthChart, type ChartConfig } from '@/components/ui/chart';
```

```tsx
const config = { revenue: { label: 'Revenue', color: 'var(--chart-1)' } } satisfies ChartConfig;

<GrowthChart title="Monthly revenue, 2026" data={data} config={config} xKey="month" />;
```

`config` names each series and picks its color. Use the chart tokens in order, `--chart-1` to `--chart-5`. They are a mono ramp, ink then four steps of gray. They read for color-blind readers, and each keeps 3:1 on cards and on the page. They switch with the theme. In a stacked chart, give each segment a 1px `stroke` in `var(--card)`, so adjacent grays stay apart. For more than five series, group the smallest into "Other".

## Examples

### Two or more series

Each key in `config` becomes a series. With two or more, a legend appears above the chart.

### Sparkline

A small trend line with no axes, for a stat tile or a table cell. It reads as one image, so its `aria-label` says what it shows, including the change: "Signups, last 12 months, up 4.2%".

<ComponentPreview name="chart-sparkline" />

### Any Recharts chart

`ChartContainer` sizes a Recharts chart to its box and themes the axes, grid, cursor and focus outline. Each series color is available as `var(--color-<key>)`. Add `ChartTooltip` with `ChartTooltipContent`, and `ChartLegend` with `ChartLegendContent`, for the Kosmos tooltip and legend.

<ComponentPreview name="chart-custom" />

Give the container a height or an aspect ratio. It is 16:9 by default. Pass a `title` to the Recharts chart to name it for screen readers. The same parts as shadcn's Chart are here under the same names, so its examples work with `color` in place of `theme` in the config.

## Accessibility

- `title` names the growth chart, and keyboard users can focus it and step through the points with the arrow keys.
- It also renders its data as a visually hidden table, so screen reader users get every value.
- Charts draw in over 300ms and skip the animation when the user prefers reduced motion.

### Parts

| Part | What it is |
| --- | --- |
| `ChartTooltip` | Recharts' `Tooltip`. Pass `content={<ChartTooltipContent />}` for rows named and colored from the config. |
| `ChartLegend` | Recharts' `Legend`. Pass `content={<ChartLegendContent />}` for entries named and colored from the config. |

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Focuses a `GrowthChart` and shows the tooltip for its first point. |
| `ArrowRight` or `ArrowLeft` | Shows the next or previous point. It stops at either end. |
| `Escape` | Hides the tooltip. The next arrow key shows it again. |

`Sparkline` takes no focus. A chart you build with `ChartContainer` and a `ChartTooltip` gets the same keys from Recharts.
