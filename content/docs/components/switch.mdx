## Usage

```tsx
import { Field, FieldContent, FieldDescription, FieldLabel } from '@/components/ui/field';
import { Switch } from '@/components/ui/switch';
```

```tsx
<Field name="email-notifications" orientation="horizontal">
  <FieldContent>
    <FieldLabel>Email notifications</FieldLabel>
    <FieldDescription>Get an email when someone assigns you a task.</FieldDescription>
  </FieldContent>
  <Switch />
</Field>
```

Put the Switch in a horizontal [Field](/docs/components/field) with its FieldLabel. The label names the switch, and clicking it flips the switch. Without a Field, wrap the Switch and its text in a `<label>`, as in the demo above, or give it an `aria-label`.

Use a Switch for a setting that takes effect right away. For a choice that waits for a Save or Submit button, use a [Checkbox](/docs/components/checkbox). Name the setting for what happens when it's on: "Email notifications", not "Turn off emails".

## Keyboard

| Key | Action |
| --- | --- |
| Space, Enter | Turns the focused switch on or off |
| Tab | Moves to the next control |

## Motion

The thumb slides in 300ms with an in-out curve. When the system asks for reduced motion, the thumb moves at once and the track's color still fades, so the state change stays visible without movement.

## API

Switch wraps the [Base UI Switch](https://base-ui.com/react/components/switch) and accepts all of its props.
