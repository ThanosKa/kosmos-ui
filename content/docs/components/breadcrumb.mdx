## Usage

```tsx
import { BreadcrumbTrail } from '@/components/ui/breadcrumb';
```

```tsx
<BreadcrumbTrail
  items={[
    { label: 'Acme', href: '/' },
    { label: 'Projects', href: '/projects' },
    { label: 'Fernhill Books', href: '/projects/fernhill' },
    { label: 'API keys' },
  ]}
/>
```

List the pages from the root down. Every page but the last links to itself; the last is the page the user is on. It shows in ink, is not a link and carries `aria-current="page"`.

## Examples

### Collapsing

`BreadcrumbTrail` fills the width it is given. When the pages do not fit, it hides the ones after the first, nearest the root first, behind an ellipsis button that opens them in a menu, in order. The first page and the current page always stay. When even those two are too wide, they truncate. Drag the corner of the box to see it.

<ComponentPreview name="breadcrumb-collapse" />

A name longer than 192px truncates in the trail. A truncated name shows in full in a tooltip when it is hovered or focused, and wraps in the menu. Screen readers always read the full name.

Give the trail a width it does not set itself, such as `flex-1 min-w-0` in a header row. In a box that grows with its content, the trail has no width to fit.

### Router links

Pass `link` to render each link, in the trail and in the menu, through your router. It gets the props of the anchor, `href` included:

```tsx
import Link from 'next/link';

<BreadcrumbTrail items={items} link={(props) => <Link {...props} />} />;
```

### Parts

Build a trail by hand from the parts when you need something `BreadcrumbTrail` does not do, such as an icon in a crumb. A hand-built trail does not collapse by itself: place a `BreadcrumbEllipsis` where you want one. Pass any icon to `BreadcrumbSeparator` to replace the chevron.

### BreadcrumbTrail

Renders a `<nav>` and accepts all of its props.

<TypeTable

### Breadcrumb

Renders a `<nav>` named "Breadcrumb" for screen readers. Put a `BreadcrumbList` inside.

### BreadcrumbList

Renders an `<ol>` that keeps its pages on one line.

### BreadcrumbItem

Renders an `<li>` for one page.

### BreadcrumbLink

Renders an `<a>` through Base UI's [`useRender`](https://base-ui.com/react/utils/use-render). Pass `render` for a router link.

### BreadcrumbPage

Renders a `<span>` with `aria-current="page"` for the page the user is on.

### BreadcrumbSeparator

Renders an `<li>` hidden from screen readers, with a chevron. Pass children to replace it.

### BreadcrumbEllipsis

A button that opens the hidden pages in a menu. Other props go to the button.
