## Usage

```tsx
import { Gauge } from '@/components/ui/gauge';
```

```tsx
<Gauge value={68} showValue aria-label="Profile completeness" />
```

A gauge is the circular sibling of [Meter](/docs/components/meter): it shows a measurement, like a score or a quota, and takes the same `min`, `max`, `format`, `tone`, `low`, `high` and `optimum`. Screen readers announce it as a meter with its value as text. A gauge has no visible label of its own, so always give it an `aria-label`, or point `aria-labelledby` at the text beside it.

For the progress of a task that finishes, such as an upload, use a progress bar instead.

## When to pick which

Meter, Gauge, Donut chart and Usage meter all show an amount against a whole. Pick by what the amount is.

- [Meter](/docs/components/meter) shows one value in a known range as a bar, with a label and the number beside it. Use it in a list, a form or a table cell.
- **Gauge** shows one value in a known range as a ring, with the number in the center. Use it in a stat card, or where a bar would be too wide.
- [Donut chart](/docs/components/donut-chart) shows how a whole splits into parts, up to five, with the total in the center. Put a legend beside it.
- [Usage meter](/docs/components/usage-meter) shows how full a token limit is and which categories fill it, such as an agent's context window.

## Examples

### Sizes

`size` is `xs` (20px), `sm` (32px), `md` (64px, the default) or `lg` (128px). The number in the center scales with it. `xs` is too small for a label: it ignores `showValue` and keeps the value text for screen readers.

<ComponentPreview name="gauge-sizes" />

### Color by region

With `tone="auto"`, the arc takes the color of its region, the way `Meter` does. With the defaults, the top third of the range is `success`, the middle `warning` and the bottom `destructive`. Set `optimum={0}` when less is better, as for disk usage. The color only repeats what the value says, so keep the value or a number beside the gauge.

<ComponentPreview name="gauge-tone" />

### Indeterminate

`indeterminate` shows a spinning arc while you work out the value. Pair it with text such as "Calculating usage…", so it is not read as zero. Under the reduced motion setting the arc pulses instead of spinning.

<ComponentPreview name="gauge-indeterminate" />

### Center content

`showValue` prints the number alone, such as `80`. Use `format` to add a unit, for example `{ style: 'percent' }` with `max={1}`.

Pass `children` to replace the number with an icon or your own text.
