## Usage

```tsx
import { Pagination, PaginationNext, PaginationPages, PaginationPrevious } from '@/components/ui/pagination';
```

```tsx
<Pagination page={page} onPageChange={setPage} pageCount={12}>
  <div className="flex items-center gap-1">
    <PaginationPrevious />
    <PaginationPages />
    <PaginationNext />
  </div>
</Pagination>
```

`Pagination` holds the page and renders a `nav` named "Pagination"; the parts inside it read the page from it, so you place them in any order and any wrapper. Pass `aria-label` when a page has two of them.

The numbered pages show the first and last page, the current one with a neighbor either side, and a gap for each run of hidden pages. The row keeps the same length on every page, so the pages never shift under the pointer, and below 640px it drops the neighbors so it fits a phone. At either end, the previous or next button turns off but keeps focus, so pressing Next up to the last page never drops focus to the page.

The counting it does comes from `@kosmos/paging`, which installs with it as `lib/paging.ts`, for your own code too: `pageCount(total, pageSize)`, `pageRows(page, pageSize, total)` for the rows a page shows, `clampPage(page, pageCount)` for after a filter shortens the list, `pageForPageSize(page, pageSize, nextPageSize)` and `paginationItems(page, pageCount)`.

## Examples

### Table footer

Pass `total` instead of `pageCount`, and Pagination counts the pages from the rows. `PaginationStatus` then shows the rows in view, such as "21–30 of 2,450", or the page, "Page 3 of 245", with `show="pages"`; screen readers hear it change. `PaginationPageSize` picks the rows per page, and keeps the first row of the page in view when the size changes.

<ComponentPreview name="pagination-table" />

Slice your rows with `pageRows`:

```tsx
import { pageRows } from '@/lib/paging';

const { from, to } = pageRows(page, pageSize, rows.length);
const visible = rows.slice(from - 1, to);
```

### Links

Pass `getPageHref` when the server renders each page, and every page becomes a link. Give the previous and next buttons children to show a label next to the arrow; below 640px they keep only the arrow, and the label stays their name.

<ComponentPreview name="pagination-links" />

For client-side routing, keep the links and push the route in `onPageChange`, which runs whenever the page changes.

### Load more

`PaginationLoadMore` goes under a list that grows instead of turning pages. The button says how many rows are left, keeps its place and its focus while the next rows load, and gives way to "All 12 shown" when every row is in, which takes the button's focus. Screen readers hear how many rows show after each load.

<ComponentPreview name="pagination-load-more" />

### Another language

Pass `aria-label` to the previous and next buttons, `pageLabel` to `PaginationPages`, `label` to `PaginationPageSize`, and a function as the child of `PaginationStatus`:

```tsx
<PaginationStatus>{({ from, to, total }) => `${from}–${to} von ${total}`}</PaginationStatus>
```

### PaginationPages

Takes every `ul` prop, plus:

<TypeTable
  type={{

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Moves through the previous button, each page, the next button and the page size select. |
| `Enter` or `Space` | Goes to the focused page, or one page back or forward. |
