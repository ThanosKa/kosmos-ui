## Usage

```tsx
import {
  Empty,
  EmptyContent,
  EmptyDescription,
  EmptyHeader,
  EmptyMedia,
  EmptyTitle,
} from '@/components/ui/empty';
```

```tsx
<Empty>
  <EmptyHeader>
    <EmptyMedia variant="icon">
      <FolderPlus />
    </EmptyMedia>
    <EmptyTitle render={<h2 />}>No projects yet</EmptyTitle>
    <EmptyDescription>Create a project to group your tasks, files and people in one place.</EmptyDescription>
  </EmptyHeader>
  <EmptyContent>
    <Button variant="secondary">New project</Button>
  </EmptyContent>
</Empty>
```

Say what is missing in the title, then what fills it in the description, and offer that step as a button. `Empty` grows to fill its container and centers its content, so put it where the list or table would be.

The parts and their names match shadcn's Empty.

### Variants

`EmptyState` is an `Empty` with the five usual reasons built in. Pick the `variant`, name what the list holds with `noun`, and it writes the icon, title and sentence. Pass `title`, `description` or `icon` to say it your own way.

<ComponentPreview name="empty-states" />

```tsx
<EmptyState variant="no-results" noun="projects" query="fernhil" onClear={clearFilters} />
<EmptyState variant="error" noun="projects" onRetry={reload} />
```

## API

Each part renders a `<div>` (`EmptyDescription` a `<p>`) and accepts all of its props. No part wraps a Base UI part.

### Parts

| Part | What it is |
| --- | --- |
| `Empty` | The centered block that fills the page, table or panel. |
| `EmptyHeader` | Holds the media, title and description. |
| `EmptyDescription` | Says why, or what to do next. A `<p>`. |
| `EmptyContent` | The next step: one or two buttons, a link or a short form. |
