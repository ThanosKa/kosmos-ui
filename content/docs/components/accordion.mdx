## Usage

```tsx
import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from '@/components/ui/accordion';
```

```tsx
<Accordion defaultValue={['plans']}>
  <AccordionItem value="plans">
    <AccordionTrigger>Can I change plans later?</AccordionTrigger>
    <AccordionContent>Yes. Upgrades apply right away.</AccordionContent>
  </AccordionItem>
</Accordion>
```

Sections are split by 1px dividers. Each heading is a button inside an `<h3>`, with a chevron that turns over as its section opens. Opening another section closes the open one.

A section grows to its height as it opens, in 300ms, and shrinks back in 150ms. When the reduced motion setting is on, it fades in and out instead, and the chevron cross-fades.

Tab moves between headings, and Enter or Space opens and closes the focused one.

## Examples

### Several sections open

Pass `multiple` to let people open more than one section at a time.

### Disabled section

Set `disabled` on an `AccordionItem`. Say why in the heading or near it, so people know what would make it available.

<ComponentPreview name="accordion-disabled" />

### Controlled

Pass `value` and `onValueChange` to `Accordion` to open sections from your own state. The value is always an array of item values, also without `multiple`.

### Searchable content

Pass `hiddenUntilFound` to `Accordion` so the browser's find in page also searches closed sections, and opens the one with a match.

## API

### Accordion

Takes every Base UI [`Accordion.Root`](https://base-ui.com/react/components/accordion) prop, such as:

<TypeTable
  type={{
    defaultValue: {
      description: 'Values of the sections open at first.',
      type: 'any[]',
    },
    value: {
      description: 'Values of the open sections, to control them.',
      type: 'any[]',
    },
    onValueChange: {
      description: 'Called with the new values when a section opens or closes.',
      type: '(value: any[]) => void',
    },
    multiple: {
      description: 'Lets more than one section be open.',
      type: 'boolean',
      default: 'false',
    },
    hiddenUntilFound: {
      description: "Lets the browser's find in page search and open closed sections.",
      type: 'boolean',
      default: 'false',
    },
    disabled: {
      description: 'Disables every section.',
      type: 'boolean',
      default: 'false',
    },
  }}
/>

### Parts

| Part | What it is |
| --- | --- |
| `AccordionItem` | One section. `value` names it, and `disabled` disables it alone. Base UI `Accordion.Item`. |
| `AccordionTrigger` | The heading row, a button inside an `<h3>`. Its children are the heading text. Base UI `Accordion.Trigger` inside `Accordion.Header`. |
| `AccordionContent` | The section body. `className` styles the inner container that holds the content and its padding. Base UI `Accordion.Panel`. |

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Moves to the next heading, or into the content of an open section. |
| `Shift` + `Tab` | Moves to the previous heading or control. |
| `Enter` or `Space` | Opens or closes the focused section. |

The arrow keys do not move between headings: each heading is a plain button in the tab order.
