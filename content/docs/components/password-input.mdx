## Usage

```tsx
import { Field, FieldLabel } from '@/components/ui/field';
import { PasswordInput } from '@/components/ui/password-input';
```

```tsx
<Field>
  <FieldLabel>Password</FieldLabel>
  <PasswordInput name="password" autoComplete="current-password" />
</Field>
```

The eye button inside the end of the input shows the password as plain text, and a second press hides it again. Seeing the password lets people check it before they submit, so a form needs no second field to type it again.

Put it in a [Field](/docs/components/field), which gives it a visible label and connects the help text and error to it. Set `autoComplete` to `current-password` on a log in form. Set it to `new-password` on a sign up form and on the page that sets a new password, so password managers suggest a strong one.

The button keeps one name, "Show password", and screen readers hear whether it is pressed. It is a regular button, so Tab reaches it after the input.
