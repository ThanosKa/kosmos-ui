## Usage

```tsx
import { Slider, SliderLabel, SliderValue } from '@/components/ui/slider';
```

```tsx
<Slider name="volume" defaultValue={60}>
  <div className="flex items-center justify-between gap-4">
    <SliderLabel>Volume</SliderLabel>
    <SliderValue />
  </div>
</Slider>
```

Slider renders one thumb for each value: a number gives one thumb, an array of two gives a range. Anything you put inside, such as a SliderLabel and a SliderValue, sits above the track. SliderLabel names the thumbs; without a visible label, pass `aria-label`.

## Keyboard

| Key | Action |
| --- | --- |
| →, ↑ | Increases the value by one `step` |
| ←, ↓ | Decreases the value by one `step` |
| Page Up, Shift + → | Increases the value by one `largeStep` |
| Page Down, Shift + ← | Decreases the value by one `largeStep` |
| Home, End | Moves to `min` or `max` |
| Tab | Moves to the next thumb, then the next control |

## Examples

### Range

Pass two values for a range. Name each thumb with `getAriaLabel`, so a screen reader can tell them apart. `format` takes `Intl.NumberFormat` options and applies them to SliderValue and to what screen readers announce.

<ComponentPreview name="slider-range" />

`getAriaLabel` is a function, so a range Slider with it renders in a Client Component.

### In a field

Inside a [Field](/docs/components/field), give the FieldLabel `nativeLabel={false}` and `render={<div />}`. It names the slider, and the Field adds a description and an error.

<ComponentPreview name="slider-field" />

### Vertical

Set `orientation="vertical"`. The slider fills the height of its container, at least 160px.

## API

Slider wraps the [Base UI Slider](https://base-ui.com/react/components/slider) and accepts all of its root props. It renders the control, track, indicator and thumbs for you.

### SliderLabel, SliderValue

SliderLabel is the slider's visible name; it names every thumb. SliderValue shows the current value, or both ends of a range, formatted with `format`. Put both inside the Slider.
