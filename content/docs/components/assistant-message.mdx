## Usage

```tsx
import { AssistantMessage, Citation } from '@/components/ui/assistant-message';
```

```tsx
<AssistantMessage role="user">How many events did Acme collect in the last 30 days?</AssistantMessage>
<AssistantMessage author={{ name: 'Acme agent' }} time="14:02" model="Claude Sonnet 5.5" sources={sources}>
  Acme collected 28,495,200 events in the last 30 days<Citation n={1} source={sources[0]} />.
</AssistantMessage>
```

The body is `children`, so render the reply with any Markdown renderer or your own components. Put a `Citation` right after the word it supports, with no space before it, so it never wraps onto a line of its own. It links to its source, opens it in a new tab and shows the source's title in a tooltip.

Below the body come a button that opens the list of `sources`, the actions and the `followUps`. Copy puts the rendered text of the reply on the clipboard, without the citation numbers. Pass `copyText` to copy something else, such as the Markdown source. Retry shows only when you pass `onRetry`. Good answer and Bad answer are toggle buttons. Pressing the pressed one clears it.

While `status` is `streaming`, a caret blinks at the end of the body, the message is marked busy for screen readers, and the sources and actions wait until the reply is done. With `status="error"`, the message shows the error under the body, with a Retry button when you pass `onRetry`.

## Examples

### Thread

Messages stack in a column with a `gap-4`. In a long thread, pass `actionsVisibility="hover"` to every reply except the latest, so only the reply people are most likely to act on shows its actions all the time.

<ComponentPreview name="assistant-message-thread" />

With `hover`, the actions appear when the pointer is over the message or when one of them has keyboard focus, and stay visible while an answer is rated. On touch screens they always show. Their row keeps its space while hidden, so nothing moves when they appear.

### Streaming

Update `children` as the reply arrives and set `status` to `done` when it ends.

<ComponentPreview name="assistant-message-streaming" />

### Error

Pass the reason as `error` and a way to try again as `onRetry`.

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Moves through the citations, the sources button and the open list, the actions and the follow-ups. With `actionsVisibility="hover"`, focusing an action shows the row. |
| `Enter` or `Space` | Opens or closes the sources, presses the focused action or picks the focused follow-up. |
