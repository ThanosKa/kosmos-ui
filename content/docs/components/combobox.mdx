## Usage

```tsx
import { Combobox, ComboboxContent, ComboboxEmpty, ComboboxInput, ComboboxItem, ComboboxList } from '@/components/ui/combobox';
```

```tsx
const projects = [
  { value: 'fernhill', label: 'Fernhill Books' },
  { value: 'cirrus', label: 'Cirrus Weather' },
];

<Combobox items={projects}>
  <ComboboxInput aria-label="Project" placeholder="Search projects" />
  <ComboboxContent>
    <ComboboxEmpty>No projects match.</ComboboxEmpty>
    <ComboboxList>
      {(project) => (
        <ComboboxItem key={project.value} value={project}>
          {project.label}
        </ComboboxItem>
      )}
    </ComboboxList>
  </ComboboxContent>
</Combobox>;
```

Combobox filters `items` by their label as people type, so the list only ever shows matches. Items shaped `{ value, label }` show their label in the field. For any other shape, pass `itemToStringLabel`. Use a [Select](/docs/components/select) when the list is short enough to read in one look, and Combobox when people would rather type than scroll.

## Examples

### Multiple values

Add `multiple`, and render the chosen values as chips in `ComboboxChips`, with a `ComboboxChipsInput` after them. From the start of the input, Left Arrow moves onto the chips, and Backspace removes the last one.

<ComponentPreview name="combobox-multiple" />

### Groups

Pass `items` as groups (`{ value, items }`) and render each with a `ComboboxGroup`, a `ComboboxGroupLabel` and a `ComboboxCollection`.

<ComponentPreview name="combobox-groups" />

### With a label

In a form, put the Combobox in a [Field](/docs/components/field). The input takes the FieldLabel as its name and turns red while the Field is invalid.

<ComponentPreview name="combobox-with-field" />

To type values that are not in a list, such as email addresses, use the [Tags input](/docs/components/tags-input), which builds on the multiple Combobox.

## API

Combobox wraps the [Base UI Combobox](https://base-ui.com/react/components/combobox). Each part takes the props of the Base UI part it renders.

### Combobox

Takes every Base UI `Combobox.Root` prop, such as:

    onValueChange: {

      type: 'boolean',
      default: 'false',

### Parts

| Part | What it is |
| --- | --- |
| `ComboboxChips` | The field of a multiple Combobox, holding the chips and the input. Base UI `Combobox.InputGroup` and `Combobox.Chips`. |
| `ComboboxChipsInput` | The input after the chips. Base UI `Combobox.Input`. |
| `ComboboxValue` | Renders the chosen value through a function child, such as the chips. Base UI `Combobox.Value`. |
| `ComboboxList` | The matching items, scrolling with an edge fade once the list outgrows the popup. Base UI `Combobox.List` in a [ScrollArea](/docs/components/scroll-area). |
| `ComboboxItem` | One option, with a check while selected. Base UI `Combobox.Item`. |
| `ComboboxEmpty` | Its text shows while nothing matches, and screen readers announce it. Base UI `Combobox.Empty`. |
| `ComboboxGroup` | One group of items. Base UI `Combobox.Group`. |
| `ComboboxGroupLabel` | The heading of a group. Base UI `Combobox.GroupLabel`. |
| `ComboboxCollection` | Renders the items of the group it sits in. Base UI `Combobox.Collection`. |
| `ComboboxSeparator` | A line between groups. Base UI `Combobox.Separator`. |

## Keyboard

| Key | Action |
| --- | --- |
| Typing | Filters the list and opens it. |
| `ArrowDown` or `ArrowUp` | Opens the list, or highlights the next or previous match. |
| `Enter` | Chooses the highlighted item. With `multiple`, it adds the item or removes a chosen one. After a search, the search clears and the list closes. |
| `Escape` | Closes the list. On a closed list, clears the value. |
| `ArrowLeft` | With `multiple`, from the start of the input: moves onto the last chip, then along the chips. |
| `Backspace` | With `multiple`, in an empty input: removes the last chip. On a chip: removes it. |
| `Tab` | Closes the list and moves to the next control. |
