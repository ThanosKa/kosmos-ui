## Usage

```tsx
import { Button } from '@/components/ui/button';
```

```tsx
<Button variant="primary">Save changes</Button>
```

Pass `variant` on every Button, even when you want the default `primary`. The call then reads the same everywhere, and a reviewer sees the intent without opening the component.

## Examples

### Variants

Use one `primary` per view for the main action. Its neighbors take `secondary` or `ghost`. `destructive` is for actions that delete or can't be undone. `item` looks like `ghost` but doesn't scale when pressed. Use it for buttons repeated in dense rows, such as nav items, table row actions and sortable column headers.

<ComponentPreview name="button-variants" />

### Sizes

`md` (30px, 14px icons) is the default and fits most toolbars and forms. Use `sm` in dense rows and `lg` for a lone call to action. In the secondary and ghost looks, an icon without its own color takes a muted tone, so the label leads.

<ComponentPreview name="button-sizes" />

### With an icon

Mark the icon with `data-icon="inline-start"` or `data-icon="inline-end"`, so the padding on that side tightens to balance it.

<ComponentPreview name="button-with-icon" />

### Icon only

Use the `icon`, `icon-sm` or `icon-lg` size and give the button an `aria-label` that names the action, such as "Open settings". The icon has no text to read out.

<ComponentPreview name="button-icon" />

### Link

With `href`, the Button renders an `<a>` with the same look, so it navigates like any link. Middle-click, open in new tab and the browser's status bar all work. For client-side routing, put `buttonVariants({ variant, size })` on your router's link component instead.

<ComponentPreview name="button-link" />

### Disabled

Nobody can click or focus a disabled button. Add `focusableWhenDisabled` when it should stay in the tab order, for example while a form saves, so focus doesn't jump.

<ComponentPreview name="button-disabled" />

## shadcn names

The Button also takes shadcn's variant and size names. When you replace shadcn's Button with this one, the shadcn components that render it, such as Dialog, Alert Dialog and Pagination, keep working without edits.

| shadcn | Renders as |
| --- | --- |
| `variant="default"` | `variant="primary"` |
| `variant="outline"` | `variant="secondary"` |
| `variant="link"` | A text link that underlines on hover and doesn't scale when pressed |
| `size="default"` | `size="md"` |
| `size="xs"` | `size="sm"` |
| `size="icon-xs"` | `size="icon-sm"` |

`data-variant` and `data-size` carry the Kosmos name, so `variant="outline"` renders `data-variant="secondary"`. Use the Kosmos names in the code you write, so every Button reads the same way.
