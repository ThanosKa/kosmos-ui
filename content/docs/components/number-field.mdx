## Usage

```tsx
import { Field, FieldLabel } from '@/components/ui/field';
import { NumberField } from '@/components/ui/number-field';
```

```tsx
<Field name="seats">
  <FieldLabel>Seats</FieldLabel>
  <NumberField defaultValue={5} min={1} max={100} />
</Field>
```

Put the NumberField in a [Field](/docs/components/field) and the FieldLabel names it. Without a Field, give it an `aria-label`. The minus and plus buttons step by `step`, and each one dims once the value reaches its end of the range. People can still type any number; on blur it is kept within `min` and `max`.

The field is 160px wide by default, which holds about nine characters. Pass a width that fits the longest value in `className` (`w-full`, `w-48`), or `h-7.5` to match a Button beside it in a toolbar.

## Examples

### Formats

`format` takes [`Intl.NumberFormat` options](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat/NumberFormat#options): currency, percent, or a unit like days. The value stays a plain number, so a percent field holds `0.75` for 75%. Set `locale` too when the page renders on the server, so the server and the browser format the number the same way.

## Keyboard

| Key | Action |
| --- | --- |
| `ArrowUp` / `ArrowDown` | Adds or takes away one `step`. |
| `Shift` + `ArrowUp` / `ArrowDown` | Adds or takes away one `largeStep`. |
| `Home` / `End` | Jumps to `min` or `max`, when set. |
| `Tab` | Moves to the next control. The minus and plus buttons are skipped, since the keys above do the same. |
