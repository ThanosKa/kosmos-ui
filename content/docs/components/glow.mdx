Ported from the hero glow of [Launch UI](https://github.com/launch-ui/launch-ui) (MIT) and restyled to the Kosmos tokens. Its copyright line lands next to the component, in `LICENSE-LAUNCH-UI`.

## Usage

```tsx
import { Glow } from '@/components/ui/glow';
```

```tsx
<section className="relative isolate overflow-hidden">
  <Glow />
  {/* the content */}
</section>
```

The Glow fills the nearest positioned parent and sits behind its content, so give the parent `relative isolate`. It takes no room and cannot shift the layout.

The color is the preset's accent. A preset with no accent gives ink, a soft gray glow on light and a soft white one on dark. It never takes the brand color.

## Examples

### Position

`top` (the default) puts the centre of the glow on the top edge, `bottom` on the bottom edge and `center` in the middle.

<ComponentPreview name="glow" />

## Accessibility

The Glow is decorative, so it is `aria-hidden` and screen readers skip it. It does not move, so reduced motion needs nothing. Keep the text on it at 4.5:1: the glow is faint enough to leave the contrast of gray text on the page intact.

## API

Glow is a `<div>` and accepts all of its props. It wraps no Base UI part.
