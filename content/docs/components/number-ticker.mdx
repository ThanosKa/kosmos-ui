Ported from the number ticker of [Magic UI](https://github.com/magicuidesign/magicui) (MIT) and restyled to the Kosmos tokens. Its copyright line lands next to the component, in `LICENSE-MAGIC-UI`.

## Usage

```tsx
import { NumberTicker } from '@/components/ui/number-ticker';
```

```tsx
<p>
  <NumberTicker value={60} /> components
</p>
```

The final number is in the markup, so it shows without JavaScript and holds the width: counting up shifts nothing, and the digits keep one width (`tabular-nums`). A number already on screen at load does not count; one further down counts when it scrolls into view.

## Accessibility

Screen readers hear the final number once; the counting digits are hidden from them. Under reduced motion the number never counts.

## API

NumberTicker is a `<span>` and accepts all of its props. It wraps no Base UI part.
