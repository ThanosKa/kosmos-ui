## Usage

```tsx
import { NumberTicker } from '@/components/ui/number-ticker';
```

```tsx
<p>
  <NumberTicker value={60} /> components
</p>
```

The final number is in the markup, so it shows without JavaScript and holds the width. Counting up shifts nothing, and the digits keep one width (`tabular-nums`). A number already on screen at load does not count. A number further down counts when it scrolls into view.

## Accessibility

Screen readers hear the final number once. They skip the counting digits. Under reduced motion the number never counts.

## API

NumberTicker is a `<span>` and accepts all its props. It wraps no Base UI part.
