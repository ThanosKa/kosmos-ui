## Usage

```tsx
import { Kbd, KbdGroup } from '@/components/ui/kbd';
```

```tsx
<KbdGroup>
  <Kbd>⌘</Kbd>
  <Kbd>K</Kbd>
</KbdGroup>
```

`Kbd` is one key and `KbdGroup` holds keys pressed together. Both render a `<kbd>` element, so a screen reader knows the text is keyboard input. Kbd only shows a shortcut; binding the keys is up to your app.

For a key drawn as an icon, give the icon the key's name so a screen reader can say it:

```tsx
<Kbd>
  <ArrowUp role="img" aria-label="Up arrow" />
</Kbd>
```

## API

### Kbd

Takes every `<kbd>` prop. Text sits at the caption size on a small key-shaped surface that works on any background.

### KbdGroup

Takes every `<kbd>` prop. Lines up its keys 4px apart.
