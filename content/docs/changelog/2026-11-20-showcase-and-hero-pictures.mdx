---
title: Showcase and hero pictures scroll in a scroll area
description: Each Showcase screen scrolls in a scroll area with an edge fade, App sidebar names its navigation, and the Hero product picture hides its scrollbar and shows a sidebar trigger.
date: 2026-11-20
---

- [Showcase](/docs/blocks/showcase): each screen scrolls in a scroll area with an edge fade, and the dashboard screen scrolls its page beside the sidebar. The screen title is an `h2` in `text-title`, and the sidebar's navigation is named "App".
- [App sidebar](/docs/blocks/app-sidebar): a new `navLabel` prop names the navigation landmark (default "Main"). Give each sidebar on a page its own name.
- [Hero product](/docs/blocks/hero): the scrollbar no longer shows in the picture, the picture's header starts with a sidebar trigger, and props such as `id` and `data-*` land on the outer section, next to `className`.

To update, run the add command again for each item.
