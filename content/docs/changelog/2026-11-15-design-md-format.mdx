---
title: Changed the preset DESIGN.md to the DESIGN.md format
description: Every preset's DESIGN.md now follows the open DESIGN.md format. It has a token block and sections for typography, layout, shadows, shapes, components and motion, and it has its own link.
date: 2026-11-15
---

The DESIGN.md that **Get code** gives on the [Presets page](/presets) now follows the open DESIGN.md format that agents and design tools read:

- **A token block** at the top with every color in light and, as `card-dark`, in dark, in the exact values of the CSS. It also holds the type roles, the radius steps and the spacing unit. It holds the core components too: buttons and their hover, text field, card, popover, menu, dialog, badge, sidebar item and tabs.
- **The sections of the format**: Overview, Colors, Typography, Layout, Elevation & Depth, Shapes, Components, Motion and Do's and Don'ts. The file used to hold the palette alone; now it names the fonts, type roles, shadows and motion too.
- **Your choice**: the accent, radius and size you picked, and a preset's own shadows, weights and component rules.

Each choice's DESIGN.md also has its own link, such as `/r/preset-soft/DESIGN.md`, so you can hand it to an agent without opening the site. The Download button gives that file.
