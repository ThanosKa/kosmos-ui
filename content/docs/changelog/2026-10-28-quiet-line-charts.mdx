---
title: Changed line charts to a quiet style
description: Lines over time are straight with a faint fill, and a previous period is the same hue at lower opacity.
date: 2026-10-28
---

- **[Chart](/docs/components/chart)**: `GrowthChart` draws straight 1.5px lines with a faint flat fill. It has no value axis, only the first and last x labels and a thin cursor line in the tooltip. New props: `previousKeys` draws a previous period as the same line at 45% opacity with no fill. `grid` adds a faint dotted vertical grid for a large chart. `legend` turns the legend on or off. `Sparkline` is straight too. Run `shadcn add` for it again to pick this up.
- **[Stats overview](/docs/blocks/stats-overview)**: the chart takes the same style, with the period before as the same line at reduced opacity instead of a dashed gray one. A change is a green or red triangle and signed number with the muted "vs. last period".
- **[Chart card](/docs/components/chart-card)**: the comparison examples use one hue for both periods, and the sample data is calmer.
- **[Stat card](/docs/components/stat-card)**: `StatCardDelta` writes the change as a green or red triangle and signed number, like Stats overview, in place of a tag. It no longer brings Badge. Run `shadcn add` for it again to pick this up.
- **[Banner](/docs/components/banner)**: the tinted banners have no divider under them. The neutral one keeps its line against the page.
