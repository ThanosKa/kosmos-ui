---
title: Added Data table
description: Parts for a table of records on TanStack Table, and the Projects table block built from them.
date: 2026-10-30
---

- **[Data table](/docs/components/data-table)**: column menus that sort and hide, and faceted filters with a count per value. It also has a search, row selection with Shift-click ranges and a bulk bar, and a footer with the rows in view and pages. TanStack Table 9 sorts, filters, counts and pages the rows; `useDataTable` sets it up, and the parts draw it with Kosmos components. The [Projects table](/docs/blocks/projects-table) block is built from them.
