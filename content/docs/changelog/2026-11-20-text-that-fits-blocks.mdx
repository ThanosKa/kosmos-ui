---
title: Text that does not fit stays readable in blocks
description: Numbers in the dashboards and overviews no longer truncate, truncated text carries a title, long words wrap, and flipped Feature rows keep their media header.
date: 2026-11-20
---

In blocks, a number is never cut, and text that is cut can be read in full.

- [Dashboard analytics](/docs/blocks/dashboard-analytics) and [Dashboard CRM](/docs/blocks/dashboard-crm): totals and values no longer truncate, and the three-column total strips stack as rows in a narrow container. Truncated names, steps, tasks and page titles carry a `title`.
- [Usage overview](/docs/blocks/usage-overview): the tile values no longer truncate, and spend from $100,000 up shows compact, such as $327.7K.
- [Stats overview](/docs/blocks/stats-overview): the metric values no longer truncate, and the chart card description carries a `title`.
- [Navbar](/docs/blocks/navbar): the banner message wraps instead of clamping to two lines, and its link moves to its own line in a narrow container. The brand name and the phone sheet links carry a `title`.
- [Members](/docs/blocks/members): the invite line carries a `title` with the whole line.
- [Kanban board](/docs/blocks/kanban-board): the target quarter no longer truncates.
- [Feature rows](/docs/blocks/feature-rows): a flipped row crops only its trailing edge, so the media header stays visible at mid widths, and the media is placed with a grid column in place of `order`. The same `wrap-break-word` now covers headings and descriptions in Feature rows, [Feature section](/docs/blocks/feature-section), [Bento](/docs/blocks/bento) and [Testimonials](/docs/blocks/testimonials).
- [Feature section](/docs/blocks/feature-section): the action slot stays inside the block, and a long button label truncates with a `title`.
- [Detail drawer](/docs/blocks/detail-drawer): a property label that wraps grows its row, since the height is now a minimum.
- [New item dialog](/docs/blocks/new-item-dialog), [Command menu](/docs/blocks/command-menu), [Page header](/docs/blocks/page-header), [Projects table](/docs/blocks/projects-table) and [Showcase](/docs/blocks/showcase): truncated text carries a `title`.

To update, run the add command again for each item.
