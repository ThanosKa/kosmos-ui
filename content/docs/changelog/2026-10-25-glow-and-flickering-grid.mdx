---
title: Added the Glow and Flickering grid backgrounds
description: Two decorative backgrounds for a hero or a call to action, in the accent color, and a landing hero without the install box.
date: 2026-10-25
---

Two new backgrounds, ported from MIT-licensed libraries and restyled to the Kosmos tokens, that install with `shadcn add`.

- [Glow](/docs/components/glow): a soft glow of the accent color behind a section, in ink when the preset sets no accent.
- [Flickering grid](/docs/components/flickering-grid): small squares that flicker behind a section. They stop drawing while off screen and show a still grid when the visitor asks for less motion.

Both are hidden from screen readers, take no room and install with the copyright line of the library they come from. The [Hero](/docs/blocks/hero) still takes an install command as an option, but the landing page of this site no longer shows one.
