---
title: Added Checkbox, Switch and Slider
description: Three more form controls that work with Field and from the keyboard, which completes the form components.
date: 2026-10-11
---

Three form controls, built on Base UI:

- [Checkbox](/docs/components/checkbox), with a mixed state for a parent that ticks a whole list. Beside a FieldLabel it takes its name from the label, and clicking the label ticks it.
- [Switch](/docs/components/switch), for settings that apply at once. The thumb slides, and it cross-fades between the ends instead when the system asks for reduced motion.
- [Slider](/docs/components/slider), for one number or a range, horizontal or vertical, with an optional label and a formatted value above the track.

The tokens add `shadow-thumb`, the shadow on the switch and slider thumbs. Run `shadcn add @kosmos/tokens` again to get it.
