---
title: Blocks hold up with worst-case data
description: Emoji and ideograph initials stay inside the avatar, long words wrap, and a long filter, quota or description no longer pushes its block wider.
date: 2026-11-20
---

Blocks now hold up with the longest names, the biggest numbers and text in other scripts.

- [Members](/docs/blocks/members), [Usage overview](/docs/blocks/usage-overview), [Dashboard analytics](/docs/blocks/dashboard-analytics), [Dashboard CRM](/docs/blocks/dashboard-crm) and [Run timeline](/docs/blocks/run-timeline): initials no longer split an emoji. A name that starts with an emoji or an ideograph shows that one glyph, so it fits the avatar. Counts such as 1,284 members carry a thousands separator.
- [Navbar](/docs/blocks/navbar), [Footer](/docs/blocks/footer), [Auth forms](/docs/blocks/auth-forms), [Command menu](/docs/blocks/command-menu) and [Projects table](/docs/blocks/projects-table): the logo letter no longer splits an emoji. The Projects table event quota shows its percent in full, such as 20,000,000%, beside the bar.
- [Page header](/docs/blocks/page-header): the Filter button stays inside the header beside many wide tabs.
- [New item dialog](/docs/blocks/new-item-dialog): a long word in the description wraps instead of widening the dialog.
- [Run timeline](/docs/blocks/run-timeline): a message with a long unbroken address wraps.
- [Kanban board](/docs/blocks/kanban-board): a card stays inside its column when its text is long, and the target wraps.

To update, run the add command again for each item.
