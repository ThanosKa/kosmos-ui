---
title: Added Kanban board, Detail drawer, Command menu and New item dialog
description: Four blocks for working with tasks, built from Kosmos components.
date: 2026-10-11
---

Four new blocks. Each installs the components it is built from:

- [Kanban board](/docs/blocks/kanban-board): columns of task cards that scroll sideways inside their container. Cards move by drag and drop, by touch or from the keyboard, and screen readers hear every move.
- [Detail drawer](/docs/blocks/detail-drawer): a side panel with one task's details. Change its status and priority, read its activity and add a comment.
- [Command menu](/docs/blocks/command-menu): a ⌘K menu with a search button. Find a task, run an action or go to a page, with second lists for changing status and assigning people.
- [New item dialog](/docs/blocks/new-item-dialog): the form for a new task. Only the title is required, and Create more keeps the dialog open for the next task.
