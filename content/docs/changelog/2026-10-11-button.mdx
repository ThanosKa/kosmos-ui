title: Added Button
description: The first Kosmos component, and the tokens every component builds on.
date: 2026-10-11
---

[Button](/docs/components/button) is the first Kosmos component. It has five variants (`primary`, `secondary`, `ghost`, `destructive`, and `item` for buttons in dense rows, which doesn't scale when pressed), three sizes plus three icon-only sizes, and it renders a link when you pass `href`.

Adding it also installs:

- `@kosmos/tokens`, the colors, shadows, radius, motion and type roles every Kosmos component uses, in light and dark.
- `@kosmos/cn`, a class helper that knows the Kosmos type roles are font sizes, so merging classes never drops a text color.

New to Kosmos? Start with [Installation](/docs/installation).
