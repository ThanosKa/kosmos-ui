---
title: Added Input, Textarea, Field and Select
description: The first form components, with labels, help text and errors connected for screen readers.
date: 2026-10-11
---

Four form components, built on Base UI:

- [Input](/docs/components/input), a single-line text input. It's 16px on small screens, so iOS doesn't zoom on focus, and the same height as a medium Button.
- [Textarea](/docs/components/textarea), a multi-line input with the same look that grows with its text.
- [Field](/docs/components/field), which gives any control a label, help text and an error, and connects them for screen readers. It runs the browser's own checks and shows an error you set from your app with `invalid`.
- [Select](/docs/components/select), a list of options behind a trigger that looks like Input, with groups, disabled items and full keyboard support.

Installing Field also installs Input.
