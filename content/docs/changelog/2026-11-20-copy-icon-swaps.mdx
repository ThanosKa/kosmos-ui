title: Copy field, Code tabs and Run timeline confirm a copy with the icon swap
description: Copy turns into Check by cross-fading out of a slight blur, the same way Asset and Assistant message swap icons.

---

Three items now swap their copy and reveal icons the way the rest of Kosmos UI does, instead of switching at once.

- [Copy field](/docs/components/copy-field): the Copy and Show buttons cross-fade their icons.
- [Code tabs](/docs/components/code-tabs): Copy turns into Check with the same swap.
- [Run timeline](/docs/blocks/run-timeline): the copy link button swaps Link for Check the same way.

With reduced motion on, the icons only fade.

To update, run the add command again for each item.
