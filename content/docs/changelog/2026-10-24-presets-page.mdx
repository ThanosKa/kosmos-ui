title: Added the Presets page and a site-wide preset
description: Pick a preset, its accent, radius and theme for the whole site, and get its CSS, registry command or DESIGN.md.
date: 2026-10-24
---

The [Presets page](/presets) shows Default, Warm, Soft, Console and Night on components, a dashboard and forms. Pick a preset, turn its accent on or off, change the radius and switch between light and dark. The preset applies to the whole site, the docs and every preview included, and stays as you move between pages. The Kosmos logo and the Pro marks keep their color.

The preset button in the header shows the current preset on every page. It opens the same picker, with Reset to go back to the Default. A link to the Presets page includes the preset, so sharing the link shares the preset.

**Get code** gives the choice three ways:

- **CSS** for light and dark, to paste after the Kosmos tokens.
- **A registry command**, such as `shadcn add @kosmos/preset-soft`, which installs the tokens with the preset over them.
- **A DESIGN.md** with every value and the rules for using them, so an agent builds new screens in the same preset.

The live dashboard on the home page now has the same preset picker.
