The [Presets page](/presets) shows Default, Warm, Soft, Console and Night on real screens. Pick a preset, turn its accent on or off, change the radius and switch between light and dark. Only the preview changes, menus, dialogs and toasts included. The address keeps your choice, so a link opens the same preview.

**Get code** gives the choice three ways:

- **CSS** for light and dark, to paste after the Kosmos tokens.
- **A registry command**, such as `shadcn add @kosmos/preset-soft`, which installs the tokens with the preset over them.
- **A DESIGN.md** with every value and the rules for using them, so an agent builds new screens in the same preset.

The live dashboard on the home page now has the same preset picker.
