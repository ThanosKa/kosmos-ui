---
title: Added Input Group and Copy Field
description: Icons, units, prefixes, keyboard hints and buttons beside a text input, and a field that copies an API key or hides it until shown.
date: 2026-10-25
---

- [Input Group](/docs/components/input-group): a text field with addons before and after its input, such as a search icon, a unit, the start of a URL, a keyboard hint or a clear button. The field lights its edge while the input has focus, a click on an addon puts the caret in the input, and it works inside a Field with its label, description and error.
- [Copy Field](/docs/components/copy-field): a read-only field that shows an API key, a webhook URL or an ID with a button that copies it. Screen readers hear when it is copied, and when the browser refuses, the value is selected so it can be copied by hand. As a secret it shows 12 dots and the last four characters until the eye button shows the value.
