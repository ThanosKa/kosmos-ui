---
title: Iris and Night keep more of the Kosmos style
description: Iris keeps the focus ring offset and the table row states, and Night's current sidebar item keeps the accent.
date: 2026-11-20
---

Two presets overrode Kosmos values their styles should not touch. Both are fixed.

- Iris: the focus ring sits 2px off a checked checkbox, a switch, a Badge, a segmented item and a link, as it does in every other preset. A table row in a card keeps the Kosmos hover and selected fills, which the card background hid.
- Night: the current sidebar item keeps the accent text color, as the preset's description says.

To update, run the add command again for the preset, or copy the new CSS from the [Presets](/presets) page.
