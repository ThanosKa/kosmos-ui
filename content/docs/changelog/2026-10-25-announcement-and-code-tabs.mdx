title: Added Announcement and Code Tabs
description: A pill that links to news above a hero, and install commands in tabs for each package manager with a copy button.
date: 2026-10-25
---

- [Announcement](/docs/components/announcement): a pill that links to news, such as a new release, with an optional badge like "New" or a version and a chevron that points to the link. Put it above a hero or a page title. Text longer than its slot wraps inside the pill.
- [Code Tabs](/docs/components/code-tabs): commands in tabs, one per package manager or platform, each in a well with a button that copies it. Screen readers hear "Command copied" once it is on the clipboard, and when the browser refuses, the command is selected so it can be copied by hand. Long commands wrap instead of scrolling, and several code tabs can share one choice. The install section of the home page is built from it.
