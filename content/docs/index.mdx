Kosmos UI is a set of components and blocks for dashboard apps: the dense screens people keep open all day, from admin panels to internal tools. Each piece is built on [Base UI](https://base-ui.com) and styled with layered shadows, quick motion and compact type.

You install them with the shadcn CLI, the same way you add shadcn/ui components. The code lands in your project as plain files, so you can read it, change it and keep it.

## What you get

- **Components.** The building blocks of a dashboard, from buttons, inputs and menus to tables, charts and a resizable sidebar. Each one has a live preview, examples and its API.
- **Blocks.** Ready-made pieces of a page built from those components: an app sidebar, a page header, a data table, stats, a kanban board, a detail drawer, a command menu and a new item dialog.
- **Tokens.** One set of CSS variables for color, shadow, radius, motion and type, in light and dark. Every component reads from it, so a change to a token reaches all of them.

The [changelog](/docs/changelog) lists every component and block as it ships, and every change to one you may already have.
