## Usage

```tsx
import { FlowChart } from '@/components/ui/flow-chart';
```

```tsx
const sources = [
  { id: 'search', label: 'Search' },
  { id: 'direct', label: 'Direct' },
];

const plans = [
  { id: 'free', label: 'Free' },
  { id: 'pro', label: 'Pro' },
];

const flows = [
  { source: 'search', target: 'free', value: 392 },
  { source: 'search', target: 'pro', value: 84 },
  { source: 'direct', target: 'free', value: 284 },
  { source: 'direct', target: 'pro', value: 80 },
];

<FlowChart
  sources={sources}
  targets={plans}
  flows={flows}
  label="New signups, from each source to the plan picked"
  unit="signups"
  sourceLabel="Source"
  targetLabel="Plan"
/>
```

The sources stack into bars on the left and the targets on the right, each as tall as its share of the total. A band joins each source to each target it sends to, as thick as the amount between them. The pill on a bar reads its share of the total. A thick band shows its amount at its left end and its share of the target at its right end.

The chart selects one band and opens a tooltip that reads its share of the source, its amount and its share of the target. Hovering a band previews it, and a click selects it. Hovering a legend item or a bar dims every band it has no part in. A click on a legend item hides that source or target and moves every band and bar to its new place. The last one shown in a column stays.

Beside the chart sit the total and, with `targetTotal`, what flows into one target, such as the signups that chose Pro. Both count to each new value. Put the chart in a [Chart card](/docs/components/chart-card), as above.

The plot is a group that screen readers name with `label`. Each band is a button that reads its source, target, amount and both shares. `Tab` reaches the selected band, the arrow keys move between bands, `Home` and `End` jump to the first and last, `Enter` selects and `Escape` clears. A hidden table lists every flow. Under the reduced motion setting the chart fades in instead of flowing, and a change fades it in again at its new layout.

Series take `--chart-1` to `--chart-5` in order down each column. Pass `color` on a source or target to set its own.

## Examples

### Entrance

The left bars grow, the bands flow across behind a soft edge, the right bars grow as it reaches them, and the tooltip opens last. By default this plays the first time a chart shows in the browser tab, and every chart after that draws at once. Changes, such as a new range, always move. [Highlight bar chart](/docs/charts/highlight-bar-chart#entrance) explains the three settings.
