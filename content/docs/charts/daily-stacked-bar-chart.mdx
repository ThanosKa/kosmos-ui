## Usage

```tsx
import { DailyStackedBarChart } from '@/components/ui/daily-stacked-bar-chart';
```

```tsx
const platforms = [
  { key: 'web', label: 'Web' },
  { key: 'ios', label: 'iOS' },
  { key: 'server', label: 'Server' },
];

const days = [
  { label: 'Oct 9', name: 'Fri, Oct 9', values: { web: 152400, ios: 256300, server: 518900 } },
  { label: 'Oct 10', name: 'Sat, Oct 10', values: { web: 152700, ios: 260100, server: 520000 } },
  { label: 'Oct 11', name: 'Sun, Oct 11', values: { web: 160600, ios: 263600, server: 546900 } },
];

<DailyStackedBarChart data={days} series={platforms} label="Events by platform, last 3 days" />
```

Each bar stacks the series from the bottom up, in the order of `series`, and each series takes the next chart color. A button above the chart shows each series' total for the whole range. Pressing it hides the series: its segments fold away, the others close up and the axis rescales. The last series on show always stays.

The chart starts on the last day, with a soft column behind its bar and a tooltip beside it. Hovering a bar previews its day, and a click or the arrow keys select it. `Home` and `End` jump to the first and last day. When the bars get too narrow for every label, the labels thin out from the last day backwards. Put the chart in a [Chart card](/docs/components/chart-card) with a title and the range, as above.

Each bar is a button that screen readers name with its day, every amount and the total. A hidden table lists every day. Under the reduced motion setting the chart fades in instead of building up, and hiding a series fades the bars in again.

## Entrance

The bars build up segment by segment from the axis, left to right, then the column rises and the tooltip opens. By default this plays the first time a chart shows in the browser tab. The [Highlight bar chart](/docs/charts/highlight-bar-chart#entrance) explains the three settings.
