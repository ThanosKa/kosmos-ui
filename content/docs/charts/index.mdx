---
title: About charts
description: Every ready-made Kosmos chart, grouped by kind, from bar and line charts to rings, candlesticks and flows.
---

Each chart is one file you install with the shadcn CLI and style with the Kosmos tokens. The charts sit in groups by kind: bars, lines and areas, rings, and the rest. Each chart reads with the pointer and the arrow keys, and repeats its data in a table for screen readers. To build a chart of your own, start from [Chart](/docs/components/chart), the Recharts container and parts, and put it on a [Chart card](/docs/components/chart-card). New charts get an entry in the [changelog](/docs/changelog).

Every chart draws in the first time a chart shows in the browser tab and appears drawn at once after that, so a dashboard that someone reloads all day stays still. Set `entrance` to change it.
