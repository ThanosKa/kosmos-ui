Component text is small and dense. Each size is a type role: one class, such as `text-body`, sets the size, line height, weight and tracking together. Hierarchy comes from weight and from `text-muted-foreground`, not from more sizes.

This page reads every value below from the tokens file. It shows each specimen on the light page and on the dark page.

## Weights

Chrome is medium (500) and content is regular (400). Buttons, nav items, tabs, menu items, field labels and badges take `font-medium`. Table cells, descriptions, input values and prose stay regular.

## Numbers

Numbers that change or line up, such as table values, stats, counters and prices, take `tabular-nums`, so the digits keep their width.

## Fonts

Kosmos targets Geist (`font-sans`) and Geist Mono (`font-mono`), and these docs use them. The tokens don't install or set fonts: your app keeps the fonts it loads, and the components use whatever `font-sans` and `font-mono` point at. [Installation](/docs/installation#fonts) shows how to load Geist and Geist Mono with `next/font`.
