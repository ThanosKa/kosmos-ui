The colors are warm neutrals with one orange accent. They use shadcn's names, so components you install from other shadcn registries pick them up too. `shadcn add @kosmos/tokens` adds them to your global CSS.

Each swatch shows the light value on the left and the dark value on the right. Click a swatch to copy its class. Every value below is read from the tokens file, so this page always matches what you install.

## Text

Grey carries the hierarchy. Values stay in `text-foreground`, and idle chrome steps back to `text-muted-foreground`. The current page in navigation (the active sidebar item, the current header tab and the current item in a nav menu) takes `text-active-foreground`: the only orange text, a darker orange than `ring` in light so it passes 4.5:1.

<ColorTokens group="text" />

## Actions

Use one `bg-primary` action per view. Its peers take the secondary or ghost look.

<ColorTokens group="actions" />

## Status

Status colors fill dots, icons and meter segments. The text beside them stays `text-foreground` or `text-muted-foreground`, with a label or icon that carries the meaning too.

## Chart

Chart series take `chart-1` to `chart-5` in order. Labels and legends stay in text colors.

<ColorTokens group="chart" />

## Tags

A tag marks a category, such as a plan or a segment. Its fill is the `tag-*` color, its text and 1px edge the matching `tag-*-foreground`, which passes 4.5:1 on the fill.
