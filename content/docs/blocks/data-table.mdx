The block brings [Table](/docs/components/table), [Checkbox](/docs/components/checkbox), [Badge](/docs/components/badge), [Avatar](/docs/components/avatar), [Dropdown menu](/docs/components/dropdown-menu), [Empty state](/docs/components/empty), [Skeleton](/docs/components/skeleton) and [Button](/docs/components/button) with it, and lands in `components/data-table.tsx`.

## Usage

```tsx
import { DataTable } from '@/components/data-table';

<DataTable rows={projects} query={query} status={tab} filters={filters} onOpen={(project) => setOpen(project)} />;
```

The `Project` type, the columns and the sample rows live in the file: change them to fit your records. Pair the table with the [page header](/docs/blocks/page-header) and pass its `query`, tab and filters straight through: its tabs are `all`, `live`, `trial` and `paused`, the values of `status`, and its filter values are the plans and platforms `filters` reads.

## What it does

- **Columns**: each project shows its name and domain, platform, plan as a colored tag, monthly active users, events in the last 30 days, the event quota, monthly revenue, a status dot and the day of its last event.
- **Event quota**: a [meter](/docs/components/meter) of how much of its plan's monthly event allowance (Free 50,000, Pro 3 million, Scale 8 million) the project used in the last 30 days. Up to 75% is green, up to 95% amber and above that red. The bar stops at full and the number beside it does not, so a project at 112% reads as red and 112%.
- **Sorting**: click the Project, Users, Events, Event quota, MRR or Last event header to sort, and again to reverse. The header carries `aria-sort`.
- **Filtering**: `query` matches the name and the domain, `status` keeps one status, and `filters` keeps the plans and platforms that are on. Within plans or within platforms a row needs any one of them; with both, it needs one of each.
- **Selection**: a checkbox per row and one for every visible row, which shows a mixed state when some are selected. With a selection, the footer swaps the row count for Clear selection, plus Export, Pause (Resume when every selected project is paused) and Delete when you pass `onAction`.
- **Totals**: the footer adds up the users, events and revenue of the visible rows.
- **Opening a row**: with `onOpen`, the project name becomes a button and a click anywhere on the row opens it too, for example in the [detail drawer](/docs/blocks/detail-drawer). Clicks on the checkbox and the actions menu do not.
- **Row actions**: each row has a menu with Open project (with `onOpen`), and Copy link, Pause project or Resume project, and Delete project (with `onAction`). Without either, the menu is hidden.
- **Loading and empty**: `loading` shows skeleton rows. When a search, status or filter hides every row, the table says so and offers Clear filters through `onClearFilters`.
- **Narrow screens**: the table scrolls sideways inside its own frame, and the page stays put.

The Delete actions are placeholders. Wire them to a confirmation dialog or an undo toast before you ship.

## API

`DataTableSort` is `{ key: 'name' | 'users' | 'events' | 'quota' | 'mrr' | 'lastEventAt'; direction: 'ascending' | 'descending' }`.

### DataTable

Takes every `<div>` prop, plus:

<TypeTable
  type={{
    rows: { description: 'The rows.', type: 'Project[]', default: 'sample projects' },
    loading: { description: 'Shows skeleton rows while the data loads.', type: 'boolean', default: 'false' },
    query: { description: 'Keeps rows whose name or domain contains this text.', type: 'string' },
    status: { description: 'Keeps rows with this status; `all` keeps every row.', type: "'all' | 'live' | 'trial' | 'paused'", default: "'all'" },
    filters: { description: 'Keeps rows on these plans (`free`, `pro`, `scale`) and platforms (`web`, `ios`, `android`, `server`). Other values are ignored.', type: 'string[]', default: '[]' },
    onOpen: { description: 'Called when a row is opened, by its name or a click on the row.', type: '(row: Project) => void' },
    onAction: { description: 'Runs Copy link, Pause, Resume or Delete project from a row menu, with that row, or Export, Pause, Resume or Delete from the bulk bar, with the selected rows. Those items show only when this is passed.', type: "(action: 'copy-link' | 'export' | 'pause' | 'resume' | 'delete', rows: Project[]) => void" },
    onClearFilters: { description: 'Adds Clear filters to the empty state shown when a search, status or filter hides every row.', type: '() => void' },
    selection: { description: 'The ids of the selected rows. Use with `onSelectionChange`.', type: 'string[]' },
    defaultSelection: { description: 'The ids selected at first, when the table keeps its own state.', type: 'string[]', default: '[]' },
    onSelectionChange: { description: 'Called with the ids of the selected rows.', type: '(ids: string[]) => void' },
    sort: { description: 'The sort. Use with `onSortChange`; `null` keeps the rows in their own order.', type: 'DataTableSort | null' },
    defaultSort: { description: 'The sort at first, when the table keeps its own state.', type: 'DataTableSort' },
    onSortChange: { description: 'Called with the new sort when a header is clicked.', type: '(sort: DataTableSort) => void' },
  }}
/>
