The block brings [Avatar](/docs/components/avatar), [Badge](/docs/components/badge), [Button](/docs/components/button), [Scroll area](/docs/components/scroll-area) and [Skeleton](/docs/components/skeleton) with it, plus [dnd-kit](https://dndkit.com) for drag and drop, and lands in `components/kanban-board.tsx`.

## Usage

```tsx
import { KanbanBoard } from '@/components/kanban-board';

<div className="flex h-[32rem]">
  <KanbanBoard items={roadmap} onItemsChange={setRoadmap} query={query} onOpen={(item) => setOpen(item)} />
</div>;
```

The board fills the height of its container, and each column scrolls on its own when its cards don't fit, with its edges fading while cards are hidden past them. When the columns are wider than the container, the board scrolls sideways. The sample data is a product roadmap: Ideas, Planned, In progress and Shipped, with cards that show the area of the product, how many customers asked for the feature, the target quarter and who builds it. Change the columns, the `KanbanItem` type and the card in the file to fit your records.

Each item names its column in `column`. The order of `items` is the order of the cards, so save the array `onItemsChange` gives you as it is. It fires once per move, when the card is dropped.

## What it does

- **Pointer**: drag a card to another place or column. A short press without moving opens it.
- **Touch**: press and hold a card for a moment, then drag.
- **Keyboard**: Tab to a card and press Space to pick it up. Up and Down move it within its column. Left and Right move it to the same place in the next column. Space drops it and Escape puts it back. Enter opens the card.
- **Screen readers** hear how to move a card when they reach it, and where it is after every step. Each card reads as one line: title, area, votes, target and assignee.
- **Columns** are open lanes split by full-height lines. Each shows its stage glyph, its title and its card count. With `onAdd`, a + button in each header adds to that column: open the [new item dialog](/docs/blocks/new-item-dialog) there with the column as the stage.
- **Cards** put the area tag and the title on top, and split them with a line from the votes, the target quarter and the assignee.
- **Search**: `query` keeps the cards whose title, area or assignee contains it.
- **Loading and empty**: `loading` shows placeholder cards. A column with no cards says so, and becomes a drop target while a card is dragged.

## Motion

While you drag, the card lifts with a stronger shadow and a slight tilt, and the cards around it slide aside in 200ms. When you drop it, it settles into its place. With the reduced motion setting on, the card doesn't tilt, nothing slides and the dropped card fades into place.

## API

### KanbanBoard

Takes every `<div>` prop, plus:

<TypeTable
  type={{
    columns: { description: 'The columns, in order.', type: 'KanbanColumn[]', default: 'Ideas, Planned, In progress, Shipped' },
    items: { description: 'The cards, controlled. Their order is the order on the board.', type: 'KanbanItem[]' },
    defaultItems: { description: 'The cards to start with when `items` is not controlled.', type: 'KanbanItem[]', default: 'a sample roadmap' },
    onItemsChange: { description: 'Called once per move, on drop, with every card in the new order.', type: '(items: KanbanItem[]) => void' },
    query: { description: 'Keeps the cards whose title, area or assignee contains this text.', type: 'string', default: "''" },
    onOpen: { description: 'Called when a card is clicked or opened with Enter.', type: '(item: KanbanItem) => void' },
    onAdd: { description: 'Shows a + button in each column header that calls this with the column id.', type: '(columnId: string) => void' },
    loading: { description: 'Shows placeholder cards.', type: 'boolean', default: 'false' },
  }}
/>
