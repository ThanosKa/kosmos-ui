## Installation

<ComponentInstall name="page-header" />

The block brings [Tabs](/docs/components/tabs), [Input](/docs/components/input), [Dropdown menu](/docs/components/dropdown-menu), [Segmented control](/docs/components/segmented-control) and [Button](/docs/components/button) with it, and lands in `components/page-header.tsx`.

## Usage

```tsx
'use client';

import { useState } from 'react';
import { PageHeader } from '@/components/page-header';
import { SidebarTrigger } from '@/components/ui/sidebar';

export default function AccountsPage() {
  const [tab, setTab] = useState('all');
  const [query, setQuery] = useState('');

  return (
    <PageHeader leading={<SidebarTrigger />} tab={tab} onTabChange={setTab} query={query} onQueryChange={setQuery}>
      {/* the page body, filtered by tab and query */}
    </PageHeader>
  );
}
```

Pass the page body as `children`: it becomes the panel of the selected tab, so screen readers hear which view it shows. Every value (tab, search text, filters, layout) works controlled, with its `on…Change` callback, or keeps its own state when you leave it out. The tabs and filters at the top of the file are sample data.

The header lays itself out by its own width, with container queries, not by the screen's. From 768px wide the tabs and the toolbar share a row; narrower, the toolbar moves under the tabs. Below 448px the primary action and Filter shrink to icons. The tabs scroll sideways when they do not fit.

## API

### PageHeader

Takes every `<div>` prop, plus:
