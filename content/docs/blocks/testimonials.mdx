## Installation

<ComponentInstall name="testimonials" />

The block brings [Avatar](/docs/components/avatar) and [Button](/docs/components/button) with it, for the people and the pause button, and lands in `components/testimonials.tsx`.

## Usage

```tsx
import { Testimonials } from '@/components/testimonials';

export function CustomerQuotes() {
  return (
    <Testimonials
      title="What teams say"
      description={null}
      featured={{
        quote: 'Acme is the one place where product, design and engineering read the same numbers.',
        name: 'Grace Whitfield',
        role: 'VP of product, Cirrus Weather',
        avatar: '/people/grace.jpg',
      }}
      testimonials={[
        { quote: 'The iOS SDK took an afternoon.', name: 'Marcus Bell', role: 'iOS lead, Brightloop Fitness' },
        { quote: 'I can see which page sells the most beans.', name: 'Owen Fitzgerald', role: 'Founder, Saltmarsh Coffee' },
      ]}
    />
  );
}
```

Give each quote its words without quotation marks, the person's `name` and, when you have them, a `role` and an `avatar` photo. A person without a photo shows their initials. The title, line and quotes at the top of the file are sample data.

## What it does

- **Featured quote**: `featured` sets one quote large and centered under the title, with the person's photo, name and role under it. `null` leaves it out.
- **Wall**: the other quotes are cards dealt into columns in turn. There are three columns from 768px, two from 576px and one below, so each column reads down in your order. The columns move up and down, each at a slightly different pace and the middle one the other way. They fade out at the top and bottom.
- **Pause**: a column glides to a stop while the mouse is on it or a finger holds it. It picks up speed again when it leaves. A small button at the bottom pauses the whole wall until you press it again. Screen readers hear it as "Pause testimonials" or "Play testimonials". The wall only moves while it is on screen.
- **Reduced motion**: when the visitor asks for less motion, nothing moves. The columns stand at full height with every quote in view, once.
- **Static**: `variant="static"` stands the columns still for everyone.
- **Screen readers**: each quote is a figure with its quote and the person who said it. The block hides the copies that keep a moving column full from them.
- **Width**: the block lays itself out by its own width, with container queries, not by the screen's.

### Testimonials

Takes every `<section>` prop, plus:

<TypeTable
  type={{
    title: { description: 'The section heading. `null` leaves it out. Then give the page a heading above the quotes.', type: 'ReactNode', default: "'Teams that know what happens next'" },
