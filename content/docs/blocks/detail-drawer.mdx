The drawer installs [Drawer](/docs/components/drawer), [Dropdown menu](/docs/components/dropdown-menu), [Select](/docs/components/select), [Textarea](/docs/components/textarea), [Avatar](/docs/components/avatar), [Badge](/docs/components/badge), [Button](/docs/components/button), [Separator](/docs/components/separator) and [Skeleton](/docs/components/skeleton) with it.

## Usage

```tsx
import { DetailDrawer } from '@/components/detail-drawer';
```

```tsx
<DetailDrawer
  task={task}
  open={open}
  onOpenChange={setOpen}
  trigger={null}
  onTaskChange={(next) => saveTask(next)}
  onComment={(body) => addComment(task.id, body)}
  onDelete={(task) => confirmDelete(task.id)}
/>
```

Without props the drawer opens from an **Open task** button and shows a sample task. Pass `trigger={null}` and control `open` to open it from somewhere else, such as a card on the [Kanban board](/docs/blocks/kanban-board). Pass your own element as `trigger` to open it from that element.

Status and priority change in place and call `onTaskChange` with the updated task. A new comment appears in the activity at once and calls `onComment`; ⌘Enter (Ctrl+Enter on Windows and Linux) sends it. **Delete task** in the more menu calls `onDelete`: ask for confirmation there before you delete anything.

The drawer slides in from the end edge and closes with Escape, a click outside, a swipe toward the edge or the close button. Focus goes back to the element that opened it.

## States

Pass `loading` to show placeholders while the task loads. Fields without a value say so (_Unassigned_, _No due date_), and a task without activity shows _No activity yet_.

## Motion

The drawer slides in over 300ms and out in 150ms. With the reduced motion setting on, it fades in and out instead.
