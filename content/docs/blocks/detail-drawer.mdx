## Usage

```tsx
import { DetailDrawer } from '@/components/detail-drawer';

<DetailDrawer
  project={project}
  open={open}
  onOpenChange={setOpen}
  trigger={null}
  onProjectChange={saveProject}
  onNote={(body) => addNote(project.id, body)}
  onAction={(action, project) => run(action, project)}
/>;
```

Without props the drawer opens from an **Open project** button and shows a sample project. Pass `trigger={null}` and control `open` to open it from a row of the [data table](/docs/blocks/data-table). A table row is already a `DetailProject`, so spread it in and add the drawer-only fields, such as `trend`, `notes` and `activity`. The `DetailProject` type and the fields live in the file: change them to fit your records.

## What it does

- **Status** changes in place and calls `onProjectChange` with the updated record. When `project.status` changes from outside, the drawer shows the new status.
- **Properties**: the plan as a colored tag, the platform and the day of the last event.
- **Last 30 days**: active users, events and monthly revenue. The event quota shows as a [meter](/docs/components/meter) with the events used out of the plan's allowance. The last item is a line of events per day from `trend`. The line has one accessible name that gives the range and the busiest day.
- **Notes**: ⌘Enter (Ctrl+Enter on Windows and Linux) or **Add note** adds one. With `onNote`, add the note to `project.activity` yourself. Without it, the drawer keeps new notes until another record opens.
- **More menu**: with `onAction`, a menu offers Copy link, Copy project ID and Delete project. Ask for confirmation before you delete.
- **Empty fields** say so (_No plan_, _No events yet_), a missing number shows a dash, and `loading` shows placeholders.
- **Closing**: Escape, a click outside, a swipe toward the edge or the close button. Focus goes back to the element that opened it.

## Motion

The drawer slides in over 300ms and out in 150ms, and the events line draws in over 300ms. With the reduced motion setting on, the drawer fades in and out instead, and the line appears at once.
