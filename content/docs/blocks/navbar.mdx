## Installation

<ComponentInstall name="navbar" />

The block brings [Button](/docs/components/button), [Drawer](/docs/components/drawer) and [Scroll area](/docs/components/scroll-area) with it, and lands in `components/navbar.tsx`.

## Usage

```tsx
'use client';

import Link from 'next/link';
import { usePathname } from 'next/navigation';
import { Navbar } from '@/components/navbar';
import { Button } from '@/components/ui/button';

export function SiteHeader() {
  const pathname = usePathname();
  return (
    <Navbar
      name="Acme"
      items={[
        {
          label: 'Product',
          links: [
            { label: 'Dashboards', href: '/features/dashboards', description: 'Charts of your events, shared with the whole team.' },
            { label: 'Funnels', href: '/features/funnels', description: 'See where users drop off between two steps.' },
          ],
        },
        { label: 'Docs', href: '/docs' },
        { label: 'Pricing', href: '/pricing' },
      ]}
      current={pathname}
      actions={
        <Button variant="primary" href="/signup">
          Start for free
        </Button>
      }
      sheetActions={
        <Button variant="secondary" size="lg" href="/login">
          Sign in
        </Button>
      }
      linkComponent={Link}
    />
  );
}
```

Pass your router's `Link` as `linkComponent`, so the name and the links move between pages without loading the whole page, and the address of the page being shown as `current`. The name, links and actions at the top of the file are sample data.

## What it does

- **Landmark**: the bar is a `<header>`. Placed outside `<main>`, `<article>` and `<section>`, it becomes the page's banner landmark, and its links sit in a navigation named by `navLabel`.
- **Sticky**: the bar stays at the top of the window on an opaque fill, so the text in it keeps its contrast over whatever scrolls under it. Its bottom edge shows once the page has scrolled.
- **Dropdowns**: a group of links opens a panel under its label on hover, on click, and with Enter, Space or the arrow keys. Each link can carry a line that says where it goes. Escape closes the panel and returns focus to its label.
- **Current page**: the link whose `href` is `current` takes the current-page color and `aria-current="page"`, with a check mark in the dropdown and the sheet. The label of the group that holds it takes the color too.
- **Actions**: buttons at the end of the bar, at every width. Hide one below the wide layout with `@max-3xl:hidden`, and repeat it in `sheetActions`.
- **Sheet**: below 768px the links move into a sheet that opens from the start edge. It keeps focus inside while it is open, closes with Escape, a tap outside or a swipe, and closes when a link is followed. Pass `menu` to put your own button there instead, such as one that opens your docs sidebar.
- **Width**: the bar lays itself out by its own width, with container queries, not by the screen's.

## API

### Navbar

Takes every `<header>` prop, plus:

  type={{
    name: { description: 'The product name beside the logo, linking to `homeHref`.', type: 'ReactNode', default: "'Acme'" },

    homeHref: { description: 'Where the name links.', type: 'string', default: "'/'" },
    items: {
      description: 'Links, and groups of links that open a dropdown. An empty array leaves them out.',

    },
    current: { description: 'The `href` of the page being shown: its link, and the group that holds it, take the current-page color.', type: 'string' },
    navLabel: { description: 'The accessible name of the navigation landmark.', type: 'string', default: "'Main'" },
    actions: { description: 'Buttons at the end of the bar, at every width. `null` leaves them out.', type: 'ReactNode', default: 'sample buttons' },
