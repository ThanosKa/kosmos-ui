## Installation

<ComponentInstall name="navbar" />

The block brings [Button](/docs/components/button), [Drawer](/docs/components/drawer), [Kbd](/docs/components/kbd) and [Scroll area](/docs/components/scroll-area) with it, and lands in `components/navbar.tsx`.

## Usage

```tsx
'use client';

import Link from 'next/link';
import { usePathname } from 'next/navigation';
import { Navbar } from '@/components/navbar';
import { Button } from '@/components/ui/button';

export function SiteHeader() {
  const pathname = usePathname();
  return (
    <Navbar
      name="Acme"
      items={[
        {
          label: 'Product',
          links: [
            { label: 'Dashboards', href: '/features/dashboards', description: 'Charts of your events, shared with the whole team.' },
            { label: 'Funnels', href: '/features/funnels', description: 'See where users drop off between two steps.' },
          ],
        },
        { label: 'Docs', href: '/docs' },
        { label: 'Pricing', href: '/pricing' },
      ]}
      current={pathname}
      actions={
        <Button variant="primary" href="/signup">
          Start for free
        </Button>
      }
      sheetActions={
        <Button variant="secondary" size="lg" href="/login">
          Sign in
        </Button>
      }
      linkComponent={Link}
    />
  );
}
```

Pass your router's `Link` as `linkComponent`, so the name and the links move between pages without loading the whole page. Pass the address of the current page as `current`. The name, links and actions at the top of the file are sample data.

## Variants

Each variant is a prop. Below 768px wide every variant collapses into the same sheet.

### Mega menu

Give an item `sections` instead of `links`: titled columns, one per section, in a wide panel. Each link takes an `icon` and a one-line `description`. In the sheet the sections become titled lists.

<ComponentPreview name="navbar-mega" />

```tsx
<Navbar
  items={[
    {
      label: 'Product',
      sections: [
        {
          title: 'Analyze',
          links: [{ label: 'Funnels', href: '/features/funnels', description: 'See where users drop off.', icon: <Filter /> }],
        },
        { title: 'Act', links: [{ label: 'Alerts', href: '/features/alerts', description: 'A message when a number moves.', icon: <Bell /> }] },
      ],
    },
  ]}
/>
```

### Centered links

`layout="center"` puts the links in the middle of the bar, with the name and the actions each taking half of the rest. The links stay centered whatever the width of either side.

<ComponentPreview name="navbar-centered" />

### Search

`search` takes a trigger, such as `NavbarSearch`. It sits before the actions from 768px wide and at the top of the sheet below it. Its `onClick` opens your search. Here it opens the [Command menu](/docs/blocks/command-menu), which ⌘K opens too. Following the trigger in the sheet closes the sheet first.

<ComponentPreview name="navbar-search" />

```tsx
function SiteHeader() {
  const [open, setOpen] = React.useState(false);
  return (
    <>
      <Navbar search={<NavbarSearch shortcut={['⌘', 'K']} onClick={() => setOpen(true)} />} />
      <CommandMenu open={open} onOpenChange={setOpen} trigger={null} />
    </>
  );
}
```

### Banner

`banner` takes a `NavbarBanner`: a short line (it wraps to two on a phone), a link and a button that dismisses it. It sits above the bar and sticks with it. The banner hides itself when dismissed; keep the choice yourself in `onDismiss` and stop rendering it next time.

## What it does

- **Landmark**: the bar is a `<header>`. Placed outside `<main>`, `<article>` and `<section>`, it becomes the page's banner landmark, and its links sit in a navigation named by `navLabel`.
- **Sticky**: the bar stays at the top of the window on an opaque fill. The text in it keeps its contrast over whatever scrolls under it. Its bottom edge shows once the page has scrolled.
- **Dropdowns**: a group of links opens a panel under its label on hover, on click, and with Enter, Space or the arrow keys. Each link can carry a line that says where it goes. Escape closes the panel and returns focus to its label. Moving to another label resizes the panel to its links and slides them in from that side; with reduced motion they fade.
- **Current page**: the link whose `href` is `current` takes the current-page color and `aria-current="page"`, with a check mark in the dropdown and the sheet. The label of the group that holds it takes the color too.
- **Actions**: buttons at the end of the bar, at every width. Hide one below the wide layout with `@max-3xl:hidden`, and repeat it in `sheetActions`.
- **Sheet**: below 768px the links move into a sheet that opens from the start edge. It keeps focus inside while it is open, closes with Escape, a tap outside or a swipe, and closes when you follow a link. Pass `menu` to put your own button there instead, such as one that opens your docs sidebar.
- **Width**: the bar lays itself out by its own width, with container queries, not by the screen's.
