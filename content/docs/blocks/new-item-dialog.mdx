The block brings [Dialog](/docs/components/dialog), [Field](/docs/components/field), [Input](/docs/components/input), [Textarea](/docs/components/textarea), [Select](/docs/components/select), [Switch](/docs/components/switch), [Avatar](/docs/components/avatar) and [Button](/docs/components/button) with it, and lands in `components/new-item-dialog.tsx`.

## Usage

```tsx
import { NewItemDialog } from '@/components/new-item-dialog';

<NewItemDialog people={members} onCreate={(values) => createAccount(values)} />;
```

The dialog opens from a **New account** button and puts focus in the name field. The sample form makes an account, shaped like the rows of the [data table](/docs/blocks/data-table); change the fields and `NewItemValues` in the file to fit your records.

To open it from the [page header](/docs/blocks/page-header)'s New button or a column of the [kanban board](/docs/blocks/kanban-board), pass `trigger={null}`, control `open`, and start the form in that column:

```tsx
<NewItemDialog
  open={open}
  onOpenChange={setOpen}
  trigger={null}
  defaultValues={{ status: columnId }}
  onCreate={addAccount}
/>
```

## What it does

- **Validation**: submitting without a name, or with a domain that isn't one, shows the error under the field and moves focus to it.
- **Creating**: `onCreate` gets the trimmed values, the domain in lowercase and ARR as a number (or `null`), then the dialog closes.
- **Create more**: with the switch on, the dialog stays open. It clears the text fields, keeps the status and owner, and confirms the record just created.
- **Fresh form**: each time the dialog opens, the form starts from `defaultValues` again.
- **Narrow containers**: the fields stack in one column when the dialog is narrower than 28rem.

## Motion

The dialog grows from 95% while it fades in over 250ms, and leaves in 150ms. With the reduced motion setting on, it only fades.
