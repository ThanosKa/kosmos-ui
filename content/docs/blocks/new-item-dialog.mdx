## Installation

The dialog installs [Dialog](/docs/components/dialog), [Field](/docs/components/field), [Input](/docs/components/input), [Textarea](/docs/components/textarea), [Select](/docs/components/select), [Switch](/docs/components/switch), [Avatar](/docs/components/avatar) and [Button](/docs/components/button) with it.

## Usage

```tsx
import { NewItemDialog } from '@/components/new-item-dialog';
```

```tsx
<NewItemDialog
  people={members}
  onCreate={(values) => createTask(values)}
/>
```

The dialog opens from a **New task** button and puts focus in the title field. Submitting without a title shows an error under the field and moves focus back to it. Submitting with one calls `onCreate` with the values and closes the dialog.

With **Create more** on, the dialog stays open after each task. It clears the title and description, keeps the status, priority and assignee for the next task, and confirms the one just created.

To open it from a column on the [Kanban board](/docs/blocks/kanban-board), pass `trigger={null}`, control `open` and start the form in that column:

```tsx
<NewItemDialog
  open={open}
  onOpenChange={setOpen}
  trigger={null}
  defaultValues={{ status: columnId }}
  onCreate={(values) => addTask(values)}
/>
```

## Motion

The dialog grows from 95% while it fades in over 250ms, and leaves in 150ms. With the reduced motion setting on, it only fades.
