## Installation

<ComponentInstall name="stats-overview" />

The block brings [Chart card](/docs/components/chart-card), [Stat card](/docs/components/stat-card), [Chart](/docs/components/chart), [Tabs](/docs/components/tabs), [Segmented control](/docs/components/segmented-control) and [Skeleton](/docs/components/skeleton) with it, and lands in `components/stats-overview.tsx`.

## Usage

```tsx
import { StatsOverview } from '@/components/stats-overview';

<StatsOverview metrics={metrics} topEvents={topEvents} />;
```

Without props it shows sample metrics. Pass the metrics and top events for each range (`7d`, `30d` and `90d`); the overview switches between them. To load a range only when it is picked, control `range` and fill in its data in `onRangeChange`.

## What it does

- **Metrics as tabs**: each metric shows its label, its value and its change against the period before, with the [Stat card](/docs/components/stat-card) value and delta: an arrow, a sign and a percentage, in a green or red tag. Set `goodWhen: 'down'` for a metric like errors, where falling is good, or `'neither'` to keep it grey. A change in a `percent` metric reads in points. The selected metric lifts onto a raised surface and drives the chart. Arrow keys move between metrics. Values of a million and up go compact (28.5M).
- **Chart**: the selected metric over the range against the same span before it, on a [Chart card](/docs/components/chart-card) with the range switch in its header, a tooltip and a hidden data table for screen readers.
- **Top events**: the most frequent events on a chart card of their own, each with a bar to scale against the first.
- **Width**: the overview lays itself out by its own width. The metrics sit four in a row on a wide container, two on a narrower one, and one per row, value beside the label, under 448px, so a value never cuts off on a phone. The top events move beside the chart from 1152px.
- **Loading, empty and error**: `loading` swaps every value for a skeleton of the same shape. A range with no points, no metrics or no events shows an empty state. `error` shows what could not load in place of the metrics, the chart and the top events, with a Try again button when you pass `onRetry`.

## API

### StatsOverview

Takes every `<section>` prop, plus:

<TypeTable
  type={{
    metrics: {
      description: 'The metrics for each range. Leave `change` out when there is no earlier period.',
      type: "Record<'7d' | '30d' | '90d', { id: string; label: string; value: number; format: 'currency' | 'number' | 'percent'; change?: number; goodWhen?: 'up' | 'down' | 'neither'; points: { label: string; current: number; previous: number }[] }[]>",
    },
    topEvents: {
      description: 'The most frequent events for each range, most frequent first. An empty list shows the empty state.',
      type: "Record<'7d' | '30d' | '90d', { name: string; count: number }[]>",
    },
    range: { description: 'The range. Use with `onRangeChange`.', type: "'7d' | '30d' | '90d'" },
    defaultRange: { description: 'The range shown at first, when the overview keeps its own state.', type: "'7d' | '30d' | '90d'", default: "'30d'" },
    onRangeChange: { description: 'Called with the newly selected range.', type: "(range: '7d' | '30d' | '90d') => void" },
    metric: { description: 'The `id` of the metric the chart shows. Use with `onMetricChange`.', type: 'string' },
    defaultMetric: { description: 'The metric shown at first, when the overview keeps its own state.', type: 'string', default: 'the first metric' },
    onMetricChange: { description: 'Called with the `id` of the newly selected metric.', type: '(metric: string) => void' },
    loading: { description: 'Shows skeletons while the data loads.', type: 'boolean', default: 'false' },
    error: { description: 'Shows an error in place of the metrics, the chart and the top events.', type: 'boolean', default: 'false' },
    onRetry: { description: 'Shows a Try again button beside the error.', type: '() => void' },
  }}
/>
