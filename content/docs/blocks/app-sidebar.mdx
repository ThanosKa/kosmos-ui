## Installation

<ComponentInstall name="app-sidebar" />

The block brings [Sidebar](/docs/components/sidebar), [Dropdown menu](/docs/components/dropdown-menu), [Avatar](/docs/components/avatar), [Kbd](/docs/components/kbd) and [Button](/docs/components/button) with it, and lands in `components/app-sidebar.tsx`.

## Usage

Place `AppSidebar` inside a `SidebarProvider`, next to the resize handle and the page:

```tsx
import { AppSidebar } from '@/components/app-sidebar';
import { SidebarInset, SidebarProvider, SidebarResizeHandle, SidebarTrigger } from '@/components/ui/sidebar';

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <SidebarProvider>
      <AppSidebar activeItem="accounts" />
      <SidebarResizeHandle />
      <SidebarInset>
        <header className="flex h-12 items-center gap-2 border-b border-border px-3">
          <SidebarTrigger />
        </header>
        {children}
      </SidebarInset>
    </SidebarProvider>
  );
}
```

The pages, saved views, workspaces and user at the top of the file are sample data: pass your own as props, or edit the defaults. Each item has an `id`; `activeItem` marks the current page, and `onNavigate` lets you route in place. The search button calls `onSearch`, so it can open a [command menu](/docs/blocks/command-menu). The block doesn't bind any keys: when your app binds ⌘K (Ctrl+K on Windows and Linux) to the same search, as the command menu does, pass `searchShortcut` and the button shows and announces it. The workspace and account menus run their actions (add workspace, profile, account settings, log out) through `onAction`; without it, those items are hidden and the user shows as plain text.

To put the same content in another surface, such as your own drawer, render `AppSidebarContent` instead of `AppSidebar`.

## What it does

- **Workspace switcher**: a menu that lists the workspaces and marks the current one. It keeps its own state, starting on `defaultWorkspace`, unless you pass `workspace` and `onWorkspaceChange`. With no workspaces, it is hidden.
- **Pages and saved views**: links with an icon and an optional count. `badgeLabel` tells screen readers what the count means ("unread").
- **Account menu**: the signed-in user, with profile, settings and log out, once you pass `onAction`. It opens upward from the bottom of the sidebar.
- **Resize, collapse and phones**: everything the [Sidebar](/docs/components/sidebar) does. From 768px up it sits beside the page; below that it opens as a drawer.

## API

### AppSidebar

Takes every [Sidebar](/docs/components/sidebar#sidebar) prop, plus the props of `AppSidebarContent`.

### AppSidebarContent

Each item is `{ id: string; label: string; href: string; icon: LucideIcon; badge?: number; badgeLabel?: string }`.
