## Installation

<ComponentInstall name="command-menu" />

The menu installs [Command](/docs/components/command), [Kbd](/docs/components/kbd), [Avatar](/docs/components/avatar) and [Button](/docs/components/button) with it.

## Usage

```tsx
import { CommandMenu } from '@/components/command-menu';
```

```tsx
<CommandMenu
  onRun={(value) => {
    if (value === 'create-task') setNewTaskOpen(true);
    if (value.startsWith('go:')) router.push(`/${value.slice(3)}`);
  }}
/>
```

The menu renders a search button that shows its shortcut. Click it, or press ⌘K (Ctrl+K on Windows and Linux) anywhere on the page. Typing filters the list, the first match stays highlighted and Enter runs it. Each command calls `onRun` with its value, such as `create-task`, `open:KOS-142` or `assign:maya`, and closes the menu. Edit the lists at the top of the file to match your app.

**Change status…** and **Assign to…** open a second list instead of running. Backspace in the empty field or Escape goes back to the main list; Escape on the main list closes the menu, and focus goes back where it was.

Use only one menu with `shortcut` on per page. Pass `trigger={null}` to hide the button and open the menu through `open` only, or your own element as `trigger`.

## Motion

The menu appears and closes without animation, because it opens from a keyboard shortcut and should be ready the moment you type.
