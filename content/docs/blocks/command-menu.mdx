## Installation

<ComponentInstall name="command-menu" />

The block brings [Command](/docs/components/command), [Kbd](/docs/components/kbd), [Avatar](/docs/components/avatar) and [Button](/docs/components/button) with it, and lands in `components/command-menu.tsx`.

## Usage

```tsx
import { CommandMenu } from '@/components/command-menu';

<CommandMenu
  onRun={(value) => {
    if (value === 'new-roadmap-item') setNewItemOpen(true);
    if (value.startsWith('go:')) router.push(`/${value.slice(3)}`);
  }}
/>;
```

The menu renders a search button that shows its shortcut. Click it, or press ⌘K (Ctrl+K on Windows and Linux) anywhere on the page. The lists at the top of the file hold sample projects with their status, actions and the pages of the [app sidebar](/docs/blocks/app-sidebar). Replace them with yours, or pass `groups` and `pages`.

## What it does

- **Search**: typing filters every list by each item's `label`, the first match stays highlighted and Enter runs it.
- **Running**: each command calls `onRun` with its value, such as `new-roadmap-item`, `open:fernhill` or `assignee:lena`, and closes the menu.
- **Second lists**: an item with a `page` opens that list instead of running (**Show roadmap items assigned to…**, **Switch workspace…**). Backspace in the empty field or Escape goes back to the main list.
- **Loading**: pass `loading` to show a loading row instead of the list while your records load.
- **Descriptions and shortcuts**: an item's `description` is a muted second line, and `keys` shows its shortcut at the end.
- **Closing**: Escape on the main list or a click outside closes the menu, and focus goes back where it was. It opens on the main list every time.
- **Shortcut**: use one menu with `hotkey` on per page. Pass `trigger={null}` to hide the button, or your own element.

## Motion

The menu appears and closes without animation, because it opens from a keyboard shortcut and should be ready the moment you type.

  type={{

### CommandMenuItem

`CommandMenuGroup` is `{ value: string; items: CommandMenuItem[] }`, and `CommandMenuPage` is `{ title: string; placeholder: string; groups: CommandMenuGroup[] }`.
