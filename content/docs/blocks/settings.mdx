## Usage

`SettingsPage` is the whole page with sample sections. Pass a handler for each card:

```tsx
import { SettingsPage } from '@/components/settings';

<SettingsPage
  profile={user}
  onSaveProfile={async (values) => {
    const response = await fetch('/api/profile', { method: 'PATCH', body: JSON.stringify(values) });
    if (!response.ok) throw new Error('That username is taken.');
  }}
  workspaceName="Acme"
  onDeleteWorkspace={deleteWorkspace}
/>;
```

Without handlers each card waits a moment and succeeds, so you can try the page first. The sections, sample values and that stand-in request are at the top of the file.

To build your own page, use the parts. A card holds its values with `useSettingsForm`:

```tsx
'use client';

import { SettingsCard, useSettingsForm } from '@/components/settings';
import { Field, FieldLabel } from '@/components/ui/field';
import { Input } from '@/components/ui/input';

export function WorkspaceCard() {
  const form = useSettingsForm({ workspace: 'Acme' }, saveWorkspace);

  return (
    <SettingsCard
      title="Workspace"
      description="The name people see when they join."
      dirty={form.dirty}
      state={form.state}
      error={form.error}
      onSave={form.save}
      onReset={form.reset}
    >
      <Field>
        <FieldLabel>Name</FieldLabel>
        <Input value={form.values.workspace} onValueChange={(value) => form.setValue('workspace', value)} />
      </Field>
    </SettingsCard>
  );
}
```

## What it does

- **Save**: off until a field differs from what was last saved, and off again after a save or Discard. The footer says "Unsaved changes", "Saving", "Changes saved" or why saving failed, and screen readers hear each change.
- **Saving**: the fields lock and the button shows a spinner. When your handler throws, its message shows in the footer and the values stay as typed.
- **Danger zone**: each action has its own button that opens a dialog that says what you lose. When the action has `confirmText`, such as the workspace name, its button stays off until you type it exactly.
- **Section links**: the block marks the link of the section in view as the current page.
- **Width**: the page lays itself out by its own width. The links sit in a column from 768px and above the cards below it, and two-column fields stack in a narrow container.

### useSettingsForm

`useSettingsForm(initial, onSave)` returns `values`, `setValue(key, value)`, `dirty`, `state`, `error`, `save` and `reset`. `onSave` gets the values and may return a promise. Throw an `Error` to show its message.

### SettingsPanel

A card for settings with nothing to save, such as an API key. Takes `title`, `description` and `headingLevel` like the card.
