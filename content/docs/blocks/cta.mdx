## Installation

<ComponentInstall name="cta" />

The block brings [Button](/docs/components/button) with it, and lands in `components/cta.tsx`.

## Usage

```tsx
import Link from 'next/link';
import { Cta } from '@/components/cta';
import { buttonVariants } from '@/components/ui/button';

export function NextStep() {
  return (
    <Cta
      title={
        <>
          Add your first project,
          <br />
          see events in a minute
        </>
      }
      action={
        <Link href="/signup" className={buttonVariants({ variant: 'primary', size: 'lg' })}>
          Start for free
        </Link>
      }
    />
  );
}
```

Put a `<br />` where the first line of the title ends. A `Button` with `href` renders a plain link, which loads the whole page; for links inside a Next.js app, style `Link` with `buttonVariants`, as above. The title and action at the top of the file are sample data.

## What it does

- **Title**: two short lines, split where you put the `<br />`. A line too long for the width wraps and balances, so the last line is never a single word.
- **Action**: one primary button under the title, the next step for a visitor who read the whole page. A label too long for the width wraps inside the button. An optional `description` adds one line between them.
- **Room**: the block has no band or background of its own. Give the section around it more space below than the others, such as `pb-28 md:pb-40`, so it closes the page on its own.
- **Width**: the block lays itself out by its own width, with container queries, not by the screen's. From 672px wide the title grows from 20px to 32px.
- **Spacing**: the block sets no padding around itself. Give the section around it the space your page uses between sections, so every block on the page keeps the same rhythm.

## API

### Cta

Takes every `<section>` prop, plus:

  type={{
